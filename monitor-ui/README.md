> **说明**: 本文档是 Monitor UI 监控模块的说明文档。目前使用的是 Vite 生成的默认模板。
> **待更新**: 建议更新此文档，添加模块的特定功能和监控说明。

## 模块概述

这是魔力淘项目的监控 UI 模块，使用 Vue 3 + TypeScript + Vite 构建。

### 技术栈
- Vue 3 (Composition API with `<script setup>`)
- TypeScript 5+
- Vite
- UnoCSS

## 快速开始

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```
