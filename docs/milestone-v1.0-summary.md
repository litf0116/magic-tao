## 关键决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| iOS + Android 上架顺序 | 同时首发 | 双端同时上线 |
| 微信支付方式 | H5 引导，不接入 IAP | 避免审核风险和 30% 抽成 |
| iOS 更新弹窗 | 审核前禁用 | 遵守 App Store 审核准则 |
| 提现入口 | 审核前隐藏 | 审核要求，上线后再开放 |
| UI 改动范围 | 最小改动 | 确保通过审核 |
| 时间标准 | DateTime.Now（北京时间） | 仅中国运营，时区一致 |
