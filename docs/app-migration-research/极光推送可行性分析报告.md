## 一、极光推送（JPush）概述

### 1.1 什么是极光推送

极光推送（JPush）是国产的第三方推送服务，由深圳市和讯华谷信息技术有限公司开发，专注于移动应用的消息推送服务。

### 1.2 极光推送特点

- ✅ **国内访问速度快**：服务器在国内，推送延迟低
- ✅ **免费额度充足**：日活100万以内免费
- ✅ **功能丰富**：支持通知、消息、标签、别名等
- ✅ **中文文档完善**：文档清晰，社区活跃
- ✅ **支持多平台**：Android、iOS、Web（有限）
- ✅ **数据统计**：提供详细的数据分析

## 三、极光推送UniApp集成方案

### 3.1 集成方式

**方法一：使用官方插件**
- 插件市场：`JG-JPush`
- 插件ID：`uni-jpush`
- 支持平台：Android、iOS

**方法二：使用极光推送官方SDK**
- 通过原生模块集成
- 更灵活，但需要配置原生插件

### 3.2 集成步骤（推荐方法）

```
1. 注册极光推送账号
   - 访问 https://www.jiguang.cn/
   - 创建应用，获取 AppKey

2. 安装UniApp插件
   - DCloud插件市场搜索"JG-JPush"
   - 导入项目

3. 配置manifest.json
   - 添加 AppKey
   - 配置权限

4. 代码集成
   - 初始化JPush
   - 处理推送回调

5. 测试
   - 发送测试推送
   - 验证接收
```

### 3.3 代码示例

```javascript
// 初始化JPush
import JPush from '@/uni_modules/jg-jpush'

export function initJPush() {
  JPush.init({
    appKey: 'your_app_key',
    channel: 'developer-default',
    production: false // 开发环境
  })

  // 监听推送
  JPush.addReceiveNotificationListener((message) => {
    console.log('收到推送', message)
    // 处理推送消息
  })

  JPush.addReceiveCustomMessageListener((message) => {
    console.log('收到自定义消息', message)
  })
}

// 设置别名（用户标识）
export function setAlias(userId) {
  JPush.setAlias(userId)
}

// 获取RegistrationID
export function getRegistrationID() {
  JPush.getRegistrationID((id) => {
    console.log('RegistrationID:', id)
  })
}
```

## 四、对项目的影响分析

### 4.1 对安卓端的影响

**优势**：
- ✅ 国内推送速度更快，用户体验更好
- ✅ 无需翻墙，服务更稳定
- ✅ 符合国内合规要求
- ✅ 中文文档，问题解决更快

**劣势**：
- ⚠️ 需要额外注册极光账号
- ⚠️ 日活超过100万需要付费（项目当前规模不涉及）

**工时影响**：
- FCM集成：6小时
- JPush集成：6小时（相同）
- **工时无变化**

### 4.2 对iOS端的影响

**无影响**：
- iOS端依然使用 Web Push（Safari通知）
- JPush不支持PWA/Web Push
- **方案不变**

### 4.3 对PWA的影响

**无影响**：
- PWA依然使用 Web Push
- JPush不支持Web Push
- **方案不变**

### 5.3 后端推送服务

后端需要集成极光推送的Server API：

```javascript
// 极光推送Server API示例
const axios = require('axios')

async function pushToAndroid(title, content, extras) {
  const url = 'https://api.jpush.cn/v3/push'

  const data = {
    platform: 'android',
    audience: 'all', // 或指定别名
    notification: {
      android: {
        alert: content,
        title: title,
        extras: extras
      }
    }
  }

  const response = await axios.post(url, data, {
    headers: {
      'Authorization': `Basic ${base64Auth}`,
      'Content-Type': 'application/json'
    }
  })

  return response.data
}
```
