# 装备数据收集快速开始

## 🚀 三种收集方式

### 方式1：手动收集（推荐新手）✅

**适合**：数据量小、需要精确控制

**步骤**：
1. 访问 https://www.molibaike.com/
2. 点击「物品装备」
3. 按类型逐个查看装备详情
4. 填写数据模板（见 `templates/equipment_template.json`）

**预计时间**：2-3天（40-60件装备）

---

### 方式2：半自动收集（推荐）⭐

**适合**：有一定技术基础、需要批量收集

**步骤**：
1. 安装Python依赖：`pip install -r scripts/requirements.txt`
2. 运行测试脚本：`python scripts/collect_sample.py`
3. 查看收集的示例数据
4. 根据需要调整脚本参数

**预计时间**：1-2天

---

### 方式3：完全自动（高级用户）🤖

**适合**：熟悉爬虫、需要收集大量数据

**步骤**：
1. 修改 `scripts/collect_equipment_data.py` 中的选择器
2. 运行完整脚本：`python scripts/collect_equipment_data.py`
3. 等待数据收集完成

**预计时间**：半天（需调试脚本）

## 💡 快速收集技巧

### 1. 使用浏览器扩展

推荐扩展：
- **Copy Table Data** - 复制表格数据
- **Table Capture** - 截取表格为图片
- **SingleFile** - 保存整个页面

### 2. 利用搜索功能

在魔力百科使用搜索快速找到装备：
- 搜索 "LV1" 查找1级装备
- 搜索 "弓类" 查找弓类装备
- 搜索 "合成" 查找有合成配方的装备

### 3. 批量下载图片

使用浏览器批量下载扩展：
- **Fatkun批量下载**
- **图片助手**

## ⚡ 最快开始（5分钟）

1. **复制模板**：
   ```bash
   cp templates/equipment_template.json data/my_equipments.json
   ```

2. **打开编辑**：
   用VS Code或任何文本编辑器打开 `data/my_equipments.json`

3. **手动填写**：
   复制模板项，修改为实际装备数据

4. **验证格式**：
   ```bash
   python -m json.tool data/my_equipments.json
   ```

5. **完成**！
   数据已准备好，可以导入系统了。
