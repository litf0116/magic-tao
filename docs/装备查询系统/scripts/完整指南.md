## 🚀 三种收集方式

### 方式1：手动收集 ⭐⭐⭐⭐⭐（推荐）

**适合**：数据量小、需要精确控制

**步骤**：
1. 访问 https://www.molibaike.com/
2. 点击「物品装备」→ 选择类型
3. 逐个查看装备详情
4. 使用模板 `templates/equipment_template.json` 填写数据
5. 保存到 `data/` 目录

**预计时间**：2-3天（40-60件装备）

---

### 方式2：半自动收集 ⭐⭐⭐⭐（技术用户）

**适合**：有一定技术基础、需要批量收集

**步骤**：
```bash
# 1. 安装依赖
pip install -r scripts/requirements.txt

# 2. 运行测试脚本
cd docs/装备查询系统/scripts
python collect_sample.py

# 3. 查看收集的数据
cat ../data/equipment_list_sample.json

# 4. 根据需要调整脚本
```

**预计时间**：1-2天

---

### 方式3：完全自动 ⭐⭐⭐（高级用户）

**适合**：熟悉爬虫、需要收集大量数据

**步骤**：
```bash
# 1. 修改脚本中的选择器（根据实际HTML结构调整）
# 2. 运行完整脚本
python collect_equipment_data.py
# 3. 等待数据收集完成
```

**预计时间**：半天（需调试脚本）

## 💡 收集技巧

### 1. 使用浏览器扩展

- **Copy Table Data** - 复制表格数据
- **Table Capture** - 截取表格
- **SingleFile** - 保存整个页面

### 2. 批量下载图片

- 右键图片 → 「图片另存为」
- 保存到：`images/equipment/`
- 命名：`{装备名称}_{等级}.png`

### 3. 快速复制模板

使用模板的5件示例装备作为起点：
- 威力短弓（武器）

- 新手铠甲（防具）
- 铜戒指（首饰）
- 火风的水晶（属性水晶）

## ⚠️ 注意事项

### 1. 数据一致性

- 统一类型名称：使用「武器」「防具」「首饰」「属性水晶」
- 统一子类型名称：使用「剑类」「弓类」「长袍」「铠甲」
- 统一品质名称：使用「普通」「优秀」「精良」「传说」「史诗」
- 统一等级格式：使用数字（1-9），不带「LV」前缀

### 2. 版权信息

- 数据仅供学习使用
- 保留数据来源标注：`"source": "molibaike.com"`
- 不用于商业用途

### 3. 数据验证

收集完成后验证：
```bash
# JSON格式验证
python -m json.tool data/equipments_武器.json
python -m json.tool data/equipments_防具.json
python -m json.tool data/equipments_首饰.json
```

## 📞 常见问题

**Q: 如何快速填充重复数据？**
A: 复制模板项，只修改不同的字段

**Q: 装备图片从哪里获取？**
A: 右键点击魔力百科的装备图片 → 「图片另存为」

**Q: 如何批量收集数据？**
A: 参考「手动收集指南.md」使用浏览器扩展

**Q: 合成配方数据在哪里找？**
A: 在装备详情页面的「合成配方」区域

**Q: 脚本运行失败怎么办？**
A: 先运行 `collect_sample.py` 测试，查看实际HTML结构
