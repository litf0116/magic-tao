## 🚀 推荐收集流程

### 第一阶段：快速验证（1小时）

1. 使用手动方式收集 **5件示例装备**
   - 武器：威力短弓
   - 防具：新手铠甲
   - 首饰：铜戒指
   - 属性水晶：火风的水晶
   - 武器：新手法杖

2. 使用模板 `templates/equipment_template.json` 填写数据
3. 保存到 `data/equipments_测试.json`

### 第二阶段：批量收集（2-3天）

#### 选项A：手动收集（推荐）

1. 访问 https://www.molibaike.com/
2. 按类型依次收集：
   - 武器类：剑类、杖类、枪类、斧类、弓类、回力镖、小刀
   - 防具类：长袍、铠甲、靴子、头盔、鞋子、衣服、盾牌、帽子
   - 首饰类：乐器、项链、头饰、戒指、耳环、头带、护身符、手环

3. 每个子类型收集 **3-5件装备**
4. 分别保存到对应的JSON文件

#### 选项B：使用半自动脚本

```bash
# 安装依赖
pip install -r scripts/requirements.txt

# 运行测试脚本
cd docs/装备查询系统/scripts
python collect_sample.py

# 查看收集的数据
cat ../data/equipment_list_sample.json
```

## 💡 收集建议

### 优先收集顺序

1. **第一阶段**（高优先级）🔴
   - 武器：弓类、剑类（热门职业）
   - 防具：铠甲、长袍（基础防御）
   - 首饰：戒指、项链（通用）

2. **第二阶段**（中优先级）🟡
   - 其他武器类型
   - 其他防具类型
   - 其他首饰类型

3. **第三阶段**（低优先级）🟢
   - 属性水晶
   - 特殊装备
   - 传说级装备

### 数据质量要求

**必填字段**：
- ✅ id（唯一标识）
- ✅ name（装备名称）
- ✅ type（主类型）
- ✅ subType（子类型）
- ✅ level（等级）
- ✅ quality（品质）
- ✅ imageUrl（图片URL或路径）

**推荐字段**：
- ⭐ attributes（属性数据）
- ⭐ description（描述）
- ⭐ requirements（使用要求）
- ⭐ dropLocations（掉落位置）

**可选字段**：
- synthesis（合成配方）
- specialEffect（特殊效果）

## ⚠️ 注意事项

### 1. 数据一致性

- 统一类型名称：使用「武器」「防具」「首饰」「属性水晶」
- 统一子类型名称：使用「剑类」「弓类」「长袍」「铠甲」等
- 统一品质名称：使用「普通」「优秀」「精良」「传说」「史诗」
- 统一等级格式：使用数字（1-9），不带「LV」前缀

### 2. 图片处理

- 推荐格式：PNG
- 推荐尺寸：64x64px（列表）、128x128px（详情）
- 命名格式：`{装备名称}_{等级}.png`
- 保存位置：`images/equipment/`

### 3. 版权信息

- 数据仅供学习使用
- 保留数据来源标注
- 不用于商业用途

## 📞 技术支持

### 常见问题

**Q1: JSON格式验证失败**
A: 使用 `python -m json.tool filename.json` 验证格式

**Q2: 如何快速填充重复数据？**
A: 使用模板复制，只修改不同的字段

**Q3: 装备图片从哪里获取？**
A: 右键点击魔力百科的装备图片，选择「图片另存为」

**Q4: 合成配方数据在哪里找？**
A: 在装备详情页面的「合成配方」区域
