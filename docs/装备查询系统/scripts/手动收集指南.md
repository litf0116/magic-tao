# 装备数据收集 - 手动收集指南

## 📋 概述

由于魔力百科网站可能需要登录或有反爬机制，建议采用**手动收集**的方式。本指南提供详细的手动收集步骤和模板。

---

## 🎯 收集范围

### 优先级 🔴 高（第一阶段）

#### 武器类（5-7件）
- 剑类：威力短弓 (LV1)、猎弓 (LV3)、精铁长弓 (LV5)
- 杖类：新手法杖 (LV1)、魔力法杖 (LV3)
- 枪类：普通长枪 (LV2)、精钢长枪 (LV5)
- 斧类：战斗斧 (LV3)、巨斧 (LV7)
- 弓类：威力短弓 (LV1)、猎弓 (LV3)
- 回力镖：飞镖 (LV2)、回旋镖 (LV4)
- 小刀：匕首 (LV1)、短刀 (LV3)

#### 防具类（5-8件）
- 铠甲：新手铠甲 (LV1)、铁铠甲 (LV3)、钢铠甲 (LV5)
- 长袍：布袍 (LV1)、法袍 (LV3)
- 盾牌：木盾 (LV1)、铁盾 (LV3)
- 头盔：皮帽 (LV2)、铁盔 (LV5)
- 靴子：皮靴 (LV2)、铁靴 (LV5)

#### 首饰类（5-8件）
- 戒指：铜戒指 (LV1)、银戒指 (LV3)
- 项链：铜项链 (LV1)、银项链 (LV3)
- 手环：皮护腕 (LV2)、铁护腕 (LV5)

### 优先级 🟡 中（第二阶段）
- 其他子类型的装备
- 合成配方数据
- 掉落位置数据

### 优先级 🟢 低（第三阶段）
- 属性水晶
- 特殊节日装备
- 传说级装备

## 🚀 收集步骤

### 步骤1：访问魔力百科

1. 打开浏览器
2. 访问：https://www.molibaike.com/
3. 点击「物品装备」

### 步骤2：按类型收集

#### 武器类收集

1. 点击「武器」
2. 选择子类型（如「弓类」）
3. 逐个点击装备查看详情
4. 填写数据收集表格

#### 数据收集表

| 名称 | 类型 | 子类型 | 等级 | 品质 | 攻击 | 防御 | 敏捷 | 命中 | 图片URL | 适用职业 | 掉落位置 |
|------|------|--------|------|------|------|------|------|------|---------|----------|----------|
| 威力短弓 | 武器 | 弓类 | 1 | 普通 | 15 | 0 | 5 | 10 | [URL] | 弓箭手、忍者 | 法兰城周边 |

### 步骤3：下载装备图片

1. 右键点击装备图片
2. 选择「图片另存为」
3. 保存到：`docs/装备查询系统/images/equipment/`
4. 命名格式：`{装备名称}_{等级}.png`

### 步骤4：整理数据

1. 将收集的数据转换为JSON格式
2. 保存到：`docs/装备查询系统/data/equipments_武器.json`
3. 使用JSON验证工具检查格式

## 🔧 实用工具

### 1. JSON编辑器

推荐使用以下工具编辑JSON文件：
- VS Code（安装JSON插件）
- Sublime Text
- 在线JSON编辑器

### 2. 数据验证

```bash
# 验证JSON格式
python -m json.tool data/equipments_武器.json

# 或使用jq
cat data/equipments_武器.json | jq .
```

### 3. 批量重命名图片

```bash
# macOS/Linux
# 将图片添加前缀
for file in images/equipment/*.png; do
  mv "$file" "images/equipment/魔力宝贝_${file##*/}"
done

# Windows PowerShell
Get-ChildItem images\equipment\*.png | Rename-Item -NewName {"魔力宝贝_" + $_.Name}
```
