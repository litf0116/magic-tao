# 魔力宝贝装备分类体系

## 📋 装备分类总览

来源：[魔力百科 - 装备分类](https://www.molibaike.com/Equipment)

魔力宝贝的装备系统分为四大主要类别，每个类别下有多个子类型。

---

## 🗡️ 武器类 (Weapons)

### 子分类（7种）

| 子类型 | 英文名 | 适用职业 | 特点 |
|--------|--------|----------|------|
| 剑类 | Sword | 剑士、骑士 | 平衡型武器，攻防适中 |
| 杖类 | Staff | 魔术师、传教士 | 魔法攻击武器，增加魔力 |
| 枪类 | Spear | 骑士、剑士 | 长距离攻击，高穿透 |
| 斧类 | Axe | 战斧斗士 | 超高攻击，命中率较低 |
| 弓类 | Bow | 弓箭手、忍者 | 远程攻击，高敏捷 |
| 回力镖 | Boomerang | 格斗士 | 投掷武器，可返回 |
| 小刀 | Dagger | 忍者、盗贼 | 快速攻击，可投掷 |

### 武器属性
- **攻击力** (Attack): 物理攻击力数值
- **魔法攻击** (Magic Attack): 魔法攻击力数值
- **命中率** (Hit Rate): 攻击命中概率
- **速度** (Speed): 攻击出手速度
- **特殊效果** (Special Effect): 特殊技能或附加效果

### 示例装备
- 威力短弓 (LV1)
- 面包剑 (LV3)
- 双刃长剑 (LV4)
- 格斗拳套 (LV5A)

## 🛡️ 防具类 (Armor)

### 子分类（8种）

| 子类型 | 英文名 | 适用职业 | 特点 |
|--------|--------|----------|------|
| 长袍 | Robe | 魔术师、传教士、巫师 | 高魔抗，低物防 |
| 铠甲 | Armor | 剑士、骑士、战斧斗士 | 高物防，低魔抗，低闪避 |
| 靴子 | Boots | 所有职业 | 移动速度 |
| 头盔 | Helmet | 战士系职业 | 头部防护 |
| 鞋子 | Shoes | 所有职业 | 类似靴子 |
| 衣服 | Clothes | 部分职业 | 基础防护 |
| 盾牌 | Shield | 剑士、骑士等 | 格挡防御 |
| 帽子 | Hat | 法师系职业 | 头部防护 |

### 防具属性
- **防御力** (Defense): 物理防御数值
- **魔法防御** (Magic Defense): 魔法防御数值
- **敏捷** (Agility): 闪避和出手速度
- **命中率** (Hit Rate): 提升攻击命中
- **闪避率** (Dodge Rate): 提升闪避概率

### 示例装备
- 十全十美安全帽 (LV1)
- 露比的衣服 (LV1)
- 亡灵铠甲 (LV9)

## 💍 首饰类 (Accessories)

### 子分类（8种）

| 子类型 | 英文名 | 功能 |
|--------|--------|------|
| 乐器 | Instrument | 特殊技能或buff |
| 项链 | Necklace | 全属性提升 |
| 头饰 | Headwear | 装饰+属性 |
| 戒指 | Ring | 特定属性提升 |
| 耳环 | Earring | 魔法相关 |
| 头带 | Headband | 敏捷相关 |
| 护身符 | Amulet | 特殊保护 |
| 手环 | Bracelet | 攻击/防御 |

### 首饰属性
- **全属性加成**: 同时提升攻击、防御、敏捷等
- **特定属性加成**: 针对某项属性提升
- **特殊技能**: 提供特殊技能或被动效果
- **抗性**: 对特定状态或属性的抵抗

### 示例装备
- 壬辰年元宵项链
- 单身勋章
- 孤单项链
- 情比金坚戒
- 武圣的臂环
- 娜蕾希亚的口琴
- 暗黑之轮
- 中量级季军戒指

## 💎 属性水晶类 (Attribute Crystals)

### 子分类（6种）

| 子类型 | 英文名 | 效果 |
|--------|--------|------|
| 普通 | Normal | 基础属性提升 |
| 怨念 | Grudge | 特殊负面效果或诅咒 |
| 元素 | Element | 元素属性加成（地水火风） |
| 希望 | Hope | 增加希望或恢复 |
| 聚能 | Focus | 聚集能量，提升伤害 |
| 强袭 | Strike | 强化攻击，增加暴击 |

### 属性水晶特点
- 可装备在武器或防具上
- 提供元素属性加成
- 可通过元素克制系统增强伤害
- 稀有度从普通到传说

### 示例装备
- 火风的水晶（6:4）- 提供火风双元素加成

## 📊 装备等级系统

### 装备等级
- 装备等级从LV1到LV9+
- 等级越高，属性越强
- 部分特殊装备为LV0（如节日限定装备）

### 装备品质
| 品质 | 颜色 | 提升比例 |
|------|------|---------|
| 普通 | 白色 | 100% |
| 优秀 | 绿色 | 120% |
| 精良 | 蓝色 | 150% |
| 传说 | 橙色 | 200% |
| 史诗 | 紫色 | 300% |

### 装备获取方式

1. **野外掉落**
   - 怪物掉落
   - 宝箱开箱

2. **任务奖励**
   - 主线任务
   - 支线任务
   - 声望奖励

3. **商店购买**
   - 各村装备店
   - 商城

4. **制作合成**
   - 生活技能制作
   - 合成配方合成

5. **交易获取**
   - 玩家间交易
   - 拍卖行

## 🔧 装备合成系统

### 合成分类
1. **武器合成**: 剑、斧、枪、弓等
2. **防具合成**: 铠甲、头盔、盾牌等
3. **首饰合成**: 戒指、项链等
4. **水晶合成**: 元素水晶组合

### 合成材料
- **基础材料**: 杉、丝、幻之银等
- **高级材料**: 幻之银LV8等
- **特殊材料**: 任务掉落、BOSS掉落

### 合成示例
**9级亡灵铠甲合成配方**:
- 12个 幻之银LV8
- 8个 杉LV8
- 5个 丝LV8

## 📈 装备优化建议

### 前期（LV1-3）
- 优先使用商店购买的装备
- 完成任务获取装备
- 注重基础属性（攻击、防御）

### 中期（LV4-7）
- 开始制作合成装备
- 关注属性克制
- 收集高品质装备

### 后期（LV8-9）
- 追求传说级装备
- 优化套装搭配
- 考虑属性水晶搭配
