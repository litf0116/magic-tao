## 1. 产品概述

### 1.1 解决的问题

用户在 PC 端已登录魔力淘，需要在移动端（H5/App/小程序）快速登录。传统方式是输入账号密码，扫码登录允许用户通过 PC 端生成的二维码，将 PC 端的登录状态"传递"到移动端。

### 1.2 使用场景

| 场景 | 描述 |
|------|------|
| **多设备协同** | PC 端浏览拍品，移动端随时出价 |
| **账号共享** | 家庭共享一个高级账号，移动端扫码使用 |
| **快速切换** | 临时借用他人设备，扫码登录无需记住密码 |

### 1.3 设计目标

- ✅ 用户无需输入账号密码，通过扫码完成移动端登录
- ✅ 移动端获得与 PC 端相同的用户身份和权限
- ✅ 登录状态安全可靠，二维码一次性使用
- ✅ 支持 H5、App、小程序多端

### 2.2 二维码状态机

```
                    ┌─────────────────┐
                    │    Pending     │ (初始状态，等待扫码)
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
              ▼              ▼              ▼
    ┌─────────────────┐   超时   ┌─────────────────┐
    │    Scanned      │ ──────>  │    Expired      │
    │   (已被扫描)     │          │    (已过期)      │
    └────────┬────────┘          └─────────────────┘
             │
    ┌────────┴────────┐
    │                 │
    ▼                 ▼
┌─────────────────┐   取消  ┌─────────────────┐
│   Confirmed     │ ──────>  │    Expired      │
│   (确认登录)    │          │    (已过期)     │
└─────────────────┘          └─────────────────┘
```

| 状态 | 说明 | 可转换目标 |
|------|------|-----------|
| `Pending` | 初始状态，等待扫码 | `Scanned`, `Expired` |
| `Scanned` | 已被移动端扫描 | `Confirmed`, `Expired` |
| `Confirmed` | 登录已确认 | - (终态) |
| `Expired` | 已过期或已取消 | - (终态) |

### 2.3 二维码格式

**URL 格式**:
```
https://www.molitao.top/h5/pages/auth/qrcode-confirm?code={code}
```

**App 专用格式** (可选):
```
molitao://qrcode?code={code}
```

| 参数 | 说明 |
|------|------|
| `code` | 32 位随机字符串，唯一标识此次二维码 |

## 3. API 设计

### 3.1 接口列表

| 接口 | 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|------|
| 生成二维码 | POST | `/api/auth/qrcode/generate` | PC 端调用 | ✅ 需要 |
| 获取用户信息 | GET | `/api/auth/qrcode/{code}` | 移动端调用 | ❌ 不需要 |
| 确认登录 | POST | `/api/auth/qrcode/confirm` | 移动端调用 | ❌ 不需要 |
| 轮询状态 | GET | `/api/auth/qrcode/{code}/status` | PC 端轮询 | ❌ 不需要 |

### 3.2 生成二维码

**请求**
```http
POST /api/auth/qrcode/generate
Authorization: Bearer {pc_user_token}
```

**响应**
```json
{
    "result": {
        "code": "abc123def456...",
        "qrContent": "https://www.molitao.top/h5/pages/auth/qrcode-confirm?code=abc123def456...",
        "expiresIn": 120
    },
    "targetUrl": null,
    "success": true,
    "error": null
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | string | 二维码唯一标识 |
| `qrContent` | string | 完整 URL，可直接生成二维码 |
| `expiresIn` | int | 有效期（秒），默认 120 秒 |

### 3.3 获取用户信息

**请求**
```http
GET /api/auth/qrcode/{code}
```

**响应**
```json
{
    "result": {
        "userId": 7509,
        "nickname": "feifei",
        "avatar": "https://thirdwx.qlogo.cn/...",
        "phone": "138****1234"
    },
    "success": true
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `userId` | long | 用户 ID |
| `nickname` | string | 昵称 |
| `avatar` | string | 头像 URL |
| `phone` | string | 脱敏手机号 |

### 3.4 确认登录

**请求**
```http
POST /api/auth/qrcode/confirm
Content-Type: application/json

{
    "code": "abc123def456..."
}
```

**响应**
```json
{
    "result": {
        "token": "eyJhbGciOiJIUzI1NiIs...",
        "tokenType": "Bearer",
        "expiresIn": 7200,
        "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
        "refreshTokenExpiresIn": 2592000,
        "user": {
            "userId": 7509,
            "nickname": "feifei",
            "avatar": "https://thirdwx.qlogo.cn/...",
            "phone": "138****1234"
        }
    },
    "success": true
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `token` | string | JWT Access Token |
| `tokenType` | string | 固定 "Bearer" |
| `expiresIn` | int | Access Token 有效期（秒），默认 2 小时 |
| `refreshToken` | string | 刷新 Token，用于自动续期 |
| `refreshTokenExpiresIn` | int | 刷新 Token 有效期（秒），默认 30 天 |
| `user` | object | 用户信息（同 3.3） |

### 3.5 轮询状态

**请求**
```http
GET /api/auth/qrcode/{code}/status
```

**响应**
```json
{
    "result": {
        "status": "pending",
        "user": null
    },
    "success": true
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | string | 状态: `pending` / `scanned` / `confirmed` / `expired` |
| `user` | object | 仅 `confirmed` 状态时返回用户信息 |

## 4. 数据模型

### 4.1 AuthRequest 表

```sql
CREATE TABLE T_AuthRequest (
    Id BIGINT NOT NULL AUTO_INCREMENT,
    Code VARCHAR(64) NOT NULL COMMENT '二维码唯一标识',
    UserId BIGINT NOT NULL COMMENT '绑定的用户ID',
    Status INT NOT NULL DEFAULT 0 COMMENT '状态: 0=Pending, 1=Scanned, 2=Confirmed, 3=Expired',
    ScannedAt DATETIME NULL COMMENT '扫码时间',
    ConfirmedAt DATETIME NULL COMMENT '确认时间',
    ExpiresAt DATETIME NOT NULL COMMENT '过期时间',
    CreationTime DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CreatorUserId BIGINT NULL,
    LastModificationTime DATETIME NULL,
    LastModifierUserId BIGINT NULL,
    PRIMARY KEY (Id),
    INDEX idx_code (Code),
    INDEX idx_userid (UserId),
    INDEX idx_expires (ExpiresAt),
    INDEX idx_status (Status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='扫码登录认证请求表';
```

### 4.2 状态枚举

```csharp
public enum AuthRequestStatus
{
    Pending = 0,      // 初始状态，等待扫码
    Scanned = 1,     // 已被扫描
    Confirmed = 2,    // 已确认登录
    Expired = 3      // 已过期
}
```

### 4.3 缓存设计

**Redis Key**: `QrCode:{code}`
**Value**: `UserId` (移动端扫码后写入)
**TTL**: 与 ExpiresAt 一致

## 5. 安全考量

### 5.1 二维码安全

| 措施 | 说明 |
|------|------|
| **一次性** | 每个 code 只能使用一次，确认后立即失效 |
| **时效性** | 默认 120 秒有效期，防止暴力破解 |
| **随机生成** | code 使用 `Guid.NewGuid().ToString("N")` 生成，无法预测 |
| **绑定用户** | code 与生成者的 UserId 绑定，无法用于其他账号 |

### 5.2 Token 安全

| 措施 | 说明 |
|------|------|
| **JWT 签名** | 使用 HS256 算法签名，防止篡改 |
| **短期 Access Token** | 默认 2 小时有效期 |
| **长期 Refresh Token** | 默认 30 天，支持自动续期 |
| **Token 回收** | 用户退出登录时撤销 Token |

### 5.3 异常处理

| 场景 | 处理方式 |
|------|---------|
| 二维码不存在 | 返回错误 "二维码不存在" |
| 二维码已过期 | 返回错误 "二维码已过期" |
| 二维码已被使用 | 返回错误 "二维码已被使用" |
| 二维码状态异常 | 返回错误 "二维码状态异常，请重新扫描" |

## 6. 多端支持

### 6.1 H5

**扫码方式**: 使用 `html5-qrcode` 库调用相机
**页面路径**: `/pages/auth/qrcode-scanner`
**确认页路径**: `/pages/auth/qrcode-confirm`

### 6.2 Flutter App

**扫码方式**: 使用 `mobile_scanner` 库调用相机
**页面路径**: `/auth/qr_code_confirm`

### 6.3 UniApp (小程序)

**扫码方式**: 使用 `uni.scanCode` 调用微信扫码
**页面路径**: `/pages/auth/qrcode-scanner`

### 6.4 URL 适配

```dart
// 解析二维码 URL
String? parseQrCode(String rawValue) {
    final uri = Uri.tryParse(rawValue);

    // App 专用格式
    if (uri?.scheme == 'molitao' && uri?.host == 'qrcode') {
        return uri?.queryParameters['code'];
    }

    // H5 URL 格式
    if (uri?.queryParameters.containsKey('code')) {
        return uri?.queryParameters['code'];
    }

    // 纯字符串格式
    if (!rawValue.contains('://') && rawValue.length > 5) {
        return rawValue;
    }

    return null;
}
```
