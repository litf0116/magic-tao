## 一、愿景与使命

### 1.1 愿景

> **成为国内领先的游戏虚拟物品交易平台**

让游戏交易更简单、更安全、更高效。

### 1.2 使命

- 为玩家提供可靠的交易服务
- 为卖家提供高效的变现渠道
- 为行业树立交易标准

## 六、禁止清单 (红线)

### 6.1 法律绝对禁止

```
⛔ 赌博性质功能 (概率类玩法涉赌)
⛔ 资金池自融 (非法集资)
⛔ 虚拟货币交易 (政策风险)
⛔ 洗钱通道 (违法)
⛔ 色情内容 (违规)
⛔ 盗版物品交易 (违法)
⛔ 违禁物品 (法律禁止)
```

### 6.2 商业底线

```
⚠️ 恶性价格战 (破坏市场)
⚠️ 虚假宣传 (失信)
⚠️ 数据倒卖 (违法)
⚠️ 强制绑定 (霸王条款)
⚠️ 诱导消费 (未成年)
```

### 6.3 品牌风险

```
⚠️ 政治敏感 (风险)
⚠️ 宗教争议 (风险)
⚠️ 恶意营销 (风险)
⚠️ 用户对立 (流失)
```
