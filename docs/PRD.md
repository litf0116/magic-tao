## 1. 产品概述

### 1.1 产品名称

**魔力淘** - 在线拍卖交易平台

### 1.2 产品定位

一款集实时拍卖、即时通讯、社交交易于一体的全平台应用，支持微信小程序、H5、Web和App多端运行。

### 1.3 目标用户

- 游戏虚拟物品买卖双方
- 寻求快速交易的买家
- 社交电商爱好者
- 拍卖品收藏者

### 1.4 核心价值

| 核心价值 | 说明 |
|----------|------|
| 实时拍卖 | 卡秒模式，刺激竞拍体验 |
| 即时通讯 | 私聊、群聊、拍卖频道 |
| 社交交易 | 帖子交易站，用户自主发布 |

## 3. 拍卖系统

### 3.1 拍卖状态流转

```
┌──────────┐     上架      ┌──────────┐     开始      ┌──────────┐     成交      ┌──────────┐
│   草稿   │ ─────────► │   上架   │ ─────────► │  拍卖中  │ ─────────► │  已成交  │
└──────────┘            └──────────┘            └──────────┘            └──────────┘
                                                                 │
                                              ┌─────────────────┘
                                              ▼
                                        ┌──────────┐
                                        │ 交易成功 │
                                        └──────────┘
                                              ▲
                                              │ 交易关闭
                        ┌──────────┐      ┌──────────┐
                        │ 卖家失约 │ ──── │ 买家失约 │
                        └──────────┘      └──────────┘
                              │
                              ▼ 交易关闭
                        ┌──────────┐
                        │ 交易关闭 │
                        └──────────┘

                        ▲
                        │ 流拍(无出价)
                        │
                  ┌──────────┐
                  │  回退   │ ◄──────
                  └──────────┘
```

### 3.2 拍卖核心功能

| 功能 | 功能描述 | 优先级 | 状态 |
|------|--------|:------:|:----:|
| 创建拍卖商品 | 创建新的拍卖品，包含名称、图片、描述、起拍价 | P0 | ✅ |
| 上架商品 | 将商品设置为上架/拍卖中状态 | P0 | ✅ |
| 拍卖列表 | 获取所有拍卖品列表（含分页筛选） | P0 | ✅ |
| 拍卖详情 | 获取单个拍卖品详情 | P0 | ✅ |
| 出价 | 用户对拍卖品进行出价 | P0 | ✅ |
| 取消出价 | 取消当前出价回退到上一出价人 | P1 | ⏳ |
| 定时结束 | 定时任务自动结束拍卖 | P0 | ✅ |
| 手动结束 | 管理员手动结束拍卖 | P0 | ✅ |
| 卡秒功能 | 卡秒模式下三倍加价 | P0 | ✅ |
| 流拍处理 | 无人出价时自动回退 | P0 | ✅ |
| 出价资格检查 | 检查用户是否有出价资格 | P0 | ✅ |
| 出价记录 | 获取拍卖出价历史 | P1 | ✅ |

### 3.3 业务规则

#### 3.3.1 出价规则

| 当前价格区间 | 最低加价 |
|------------|----------|
| ≤1000元 | 5元 |
| 1000~2000元 | 10元 |
| 2000~5000元 | 20元 |
| 5000~10000元 | 50元 |
| >10000元 | 100元 |

#### 3.3.2 卡秒模式

- **触发条件**: 拍卖剩余时间 ≤ 5分钟
- **加价规则**: 三倍加价 (如普通10元，卡秒30元)
- **状态显示**: 实时展示卡秒模式状态
- **关闭条件**: 拍卖结束或管理员手动关闭

#### 3.3.3 出价资格检查

| 检查项 | 规则 |
|--------|------|
| 登录状态 | 已登录用户 |
| 禁言状态 | 未被禁言 |
| 黑名单 | 不在黑名单 |
| 保证金 | 等级0需≥50元魔力值 |
| 昵称格式 | 非默认格式 |
| 拍卖状态 | 必须是拍卖中 |

**连接流程**:

2. 建立 WebSocket 连接
3. 订阅频道: `/ws/sub-channel`
4. 接收消息: 监听 `ReceiveMessage` / `ReceiveChannelMessage`
