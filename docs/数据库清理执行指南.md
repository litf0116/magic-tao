    CASE

    COUNT(*) AS '用户数量'

GROUP BY 
    CASE 
        WHEN HeadImgUrl LIKE 'wxfile://%' OR HeadImgUrl LIKE 'http://tmp_%' OR HeadImgUrl LIKE 'file://%' THEN '❌ 非法头像'
        WHEN HeadImgUrl IS NULL OR HeadImgUrl = '' THEN '⚪ 空头像'
        WHEN HeadImgUrl LIKE 'https://cdn.molitao.top%' THEN '✅ CDN头像'
        ELSE '⚠️ 其他头像'

        WHEN HeadImgUrl LIKE 'wxfile://%' OR HeadImgUrl LIKE 'http://tmp_%' OR HeadImgUrl LIKE 'file://%' THEN 1
        WHEN HeadImgUrl IS NULL OR HeadImgUrl = '' THEN 2
        WHEN HeadImgUrl LIKE 'https://cdn.molitao.top%' THEN 3
        ELSE 4
    END;

### ⚠️ 注意事项

1. **生产环境操作务必谨慎**
   - 建议先在测试环境验证
   - 确保有数据库备份

   ```sql

   ```
