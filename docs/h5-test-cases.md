## 已知问题和修复记录

### Bug-001: 登录后跳转逻辑错误
- **问题描述**: H5 环境使用 `uni.getCurrentPages()` 报错
- **修复方案**: 使用 `window.history.length` 判断
- **Commit**: ee9c016

### Bug-002: 用户头像校验过于严格
- **问题描述**: 非特定 CDN 域名的头像提示"上传未完成"
- **修复方案**: 支持任意 HTTP/HTTPS 地址
- **Commit**: 0f00d78

### Bug-003: 编辑帖子富文本内容不回显
- **问题描述**: 编辑时富文本内容为空
- **修复方案**: 添加 `preRender` 调用
- **Commit**: 8a86db7

### Bug-004: 编辑帖子提交验证失败
- **问题描述**: 提交冗余字段导致后端验证失败
- **修复方案**: 只提交必要字段
- **Commit**: 270fac8

### Bug-005: 交易站分页数据重复
- **问题描述**: SkipCount 计算错误
- **修复方案**: 使用 `(page - 1) * pageSize`
- **Commit**: 0165c02

### Bug-006: H5 滚动公告无限递归
- **问题描述**: `uni.createSelectorQuery()` 在 H5 导致递归
- **修复方案**: H5 使用 CSS 动画
- **Commit**: a5caddd

### Bug-007: H5 聊天录音功能报错
- **问题描述**: `uni.getRecorderManager()` H5 不支持
- **修复方案**: 条件编译移除 H5 录音功能
- **Commit**: dc1ae6d
