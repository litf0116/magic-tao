## 三、核心业务流程

### 3.1 秒杀流程

```
1. 用户进入秒杀场
2. 检查魔力值（新用户需充值51）
3. 查看拍品详情
4. 点击出价按钮
5. 输入出价金额（验证最低出价、卡秒模式三倍加价）
6. 确认出价
7. 实时显示出价结果
8. 秒杀结束，成交用户与秒杀师建立聊天
```

### 3.2 充值流程

```
1. 用户点击魔力值充值
2. 调用微信支付 API
3. 支付成功后更新魔力值
4. 显示支付成功提示
```

### 3.3 交易站流程

```
1. 浏览帖子列表
2. 分类筛选/搜索
3. 查看帖子详情
4. 联系卖家（私聊）
5. 发布帖子（卖家）
```

## 四、移动端 UI 设计要点

### 4.1 设计风格

- **主题色**: #F4835a（橙色）- 活力、热情
- **辅助色**: 
  - 成功绿: #52c41a
  - 警告橙: #fa8c16
  - 信息蓝: #1890ff
- **字体**: 系统默认字体，主字号 28-34rpx
- **圆角**: 统一 8-16rpx
- **阴影**: 轻微阴影提升层次感

### 4.2 布局原则

1. **移动端优先**: 适配 375px 宽度
2. **触控友好**: 按钮最小高度 80rpx
3. **信息层次**: 重要信息突出显示
4. **导航清晰**: 底部 TabBar + 顶部导航栏

### 4.3 关键页面设计

#### 首页
- 顶部品牌区（高度 160px）
- 入口卡片区（两列布局）
- 轮播广告区
- 广告位网格（两列）

#### 秒杀场
- 顶部公告栏（固定）
- 聊天消息区（滚动）
- 右侧悬浮按钮（秒杀榜、新消息）
- 底部出价区（固定）
- 弹窗（拍品详情、出价规则）

#### 个人中心
- 用户信息卡片
- 统计数据（两列）
- 功能网格（四列）

#### 交易站
- 分类横向滚动
- 搜索框
- 热词标签
- 帖子列表（卡片式）

## 五、技术实现建议

### 5.1 前端技术栈

- **框架**: Vue 3 + TypeScript
- **UI 组件**: 
  - uv-ui（已使用）
  - 自定义组件
- **状态管理**: Pinia
- **网络请求**: Axios
- **WebSocket**: 原生 WebSocket

### 5.2 关键功能实现

1. **秒杀实时性**: WebSocket 长连接
2. **支付功能**: 微信支付 SDK
3. **消息推送**: 极光推送（App）、订阅消息（小程序）
4. **图片处理**: CDN + 图片压缩

### 5.3 性能优化

1. **列表虚拟滚动**: 长列表优化
2. **图片懒加载**: 减少首屏加载
3. **请求防抖**: 搜索输入
4. **缓存策略**: 本地存储
