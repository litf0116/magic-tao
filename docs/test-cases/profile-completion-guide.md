# 账号绑定与完善功能测试用例

## 功能概述

用户通过微信扫码登录后，系统会检测用户是否已绑定手机号。若未绑定，则弹出引导页面，要求用户完善以下信息：
- 手机号（必填）
- 用户名（必填）
- 密码（必填）

完善后，用户可以使用账号密码（手机号/用户名 + 密码）或继续使用扫码方式登录。

## 测试数据准备

### 测试用户准备

| 用户类型 | 准备方式 | 说明 |
|----------|----------|------|
| 新用户（无手机号） | 重置用户手机号为NULL | 用于测试引导弹出 |
| 已绑定用户 | 使用已有账号 | 用于测试不弹出引导 |

### SQL准备

```sql
-- 重置用户手机号用于测试（用户ID替换为实际值）
UPDATE AbpUsers SET PhoneNumber = NULL, SkipProfileCompletion = FALSE WHERE Id = 7509;

-- 验证用户状态
SELECT Id, UserName, PhoneNumber, LENGTH(Password) as PwdLen, SkipProfileCompletion 
FROM AbpUsers WHERE Id = 7509;
```

## 风险项

| 风险项 | 缓解措施 |
|--------|----------|
| 用户名唯一性冲突 | 后端已校验，提示用户更换 |
| 手机号唯一性冲突 | 后端已校验，提示用户更换 |
| 修改UserName影响扫码登录 | 无影响，扫码登录通过AbpUserLogins表查找 |
