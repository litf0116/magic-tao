- `4` = 部分退款

## 常见问题

### 1. Token 生成失败

**原因**: GenerateTokenForUser 接口限制只能从本地 IP 访问

**解决**: 确保从 localhost (127.0.0.1) 访问

### 2. 订单创建失败

**原因**: 用户未认证或 Token 过期

**解决**: 重新生成 Token

### 3. 数据库连接失败

**原因**: MySQL 服务未启动或连接配置错误

**解决**: 检查 MySQL 服务状态和配置参数
