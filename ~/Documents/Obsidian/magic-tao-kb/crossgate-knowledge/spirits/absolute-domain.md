# 绝对领域机制

## 核心概念

绝对领域（Absolute Domain）是精灵变身系统的核心防御机制，通过"Rebirth Effect"结界在变身当回合提供无敌状态。

## Rebirth Effect结界

**触发条件：**
- 精灵变身激活当回合
- 自动发动，无需手动操作
- 装备精灵之卵后战斗开始可选变身

**防御效果：**

| 防御类型 | 效果说明 | 持续时间 |
|---------|---------|---------|
| 物理攻击 | 完全抵挡所有物理攻击 | 1回合 |
| 魔法攻击 | 完全抵挡所有魔法攻击 | 1回合 |
| 混合攻击 | 物理+魔法攻击均无效 | 1回合 |
| 特殊攻击 | 战栗袭心等特殊技能无效 | 1回合 |

**重要限制：**
- 装备耐久度仍会减少（受攻击次数影响）
- 技能消耗魔法值正常扣除
- 不防止状态异常（毒、醉等）

## 结界解除规则

**自动解除条件：**
- 变身后第二回合未受攻击
- 战斗回合结束时结界消失
- 登出游戏后效果消失

**主动解除：**
- 再次点击"精灵变身"选项
- 变身状态关闭
- 结界效果立即消失

## 变身状态维持

**持续时间计算：**
- 基于爆发值消耗速度
- 每次行动消耗爆发值
- 行动包括：攻击、技能、防御、闪躲、换位、宠物替换

**消耗公式（推测）：**
```
爆发值消耗 = 基础消耗 × 精灵卵等级 × 行动次数
```

## 战斗策略应用

**最佳使用时机：**

| 战斗场景 | 推荐策略 | 说明 |
|---------|---------|------|
| BOSS战首回合 | 必定使用 | 招架BOSS首轮强力攻击 |
| 多敌人围攻 | 战术使用 | 等待队友清怪后再解除 |
| 状态异常威胁 | 不推荐 | 结界不防状态异常 |
| 装备耐久紧张 | 慎用 | 装备仍会损耗 |

**队配合策略：**
1. 变身角色承受首回合攻击
2. 队友在变身期间集中攻击
3. 第二回合解除变身恢复正常输出

## 与其他防御机制对比

| 防御机制 | 效果范围 | 持续时间 | 消耗资源 |
|---------|---------|---------|---------|
| 绝对领域 | 100%防御 | 1回合 | 爆发值 |
| 防御技能 | 50%消减 | 1回合 | 魔法值 |
| 圣骑护卫 | 100%护卫 | 1回合 | 魔法值 |
| 保护魔法 | 队友共享 | 多回合 | 魔法值 |

## 生产系绝对领域

**非战斗场景：**
- 生产系精灵变身不触发绝对领域
- 仅提升制作能力
- 无防御效果

**采集系特殊：**
- 采集不触发战斗结界
- 仅提升采集品质
- 消耗卡时而非爆发值

## 属性克制影响

**精灵卵属性与对手水晶：**

```
属性加成公式：
IF 精灵卵属性==地：
  地属性×[(200×RAND(95,105)+50)/100]%

IF 精灵卵属性==水：
  水属性×[(200×RAND(95,105)+50)/100]%

IF 精灵卵属性==火：
  火属性×[(200×RAND(95,105)+50)/100]%

IF 精灵卵属性==风：
  风属性×[(200×RAND(95,105)+50)/100]%
```

**属性计算规则：**
- 1格属性=10
- 10格属性=100
- 属性下限为0，无上限
- 变身后才有属性加成

## 变身失败处理

**非精灵卵变身系统（变身技能）：**

| 失败结果 | 出现概率 | 说明 |
|---------|---------|------|
| 变成地上物品 | 随机 | 石头、小草等 |
| 变成图鉴宠物 | 随机 | 已登录图鉴宠物 |
| 无变化 | 随机 | 变身失败 |

**精灵卵变身系统：**
- 精灵卵变身必定成功
- 无失败概率
- 仅消耗爆发值
