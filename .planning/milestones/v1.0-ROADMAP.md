## 里程碑总结

### 关键决策

| 决策 | 结果 |
|------|------|
| iOS + Android 同时首发 | ✓ Good |
| 微信支付走 H5 引导，不接入 IAP | ✓ Good |
| iOS 审核前禁用更新弹窗 | ✓ Good |
| 提现入口在审核前隐藏 | ✓ Good |
| UI 范围最小改动 | ✓ Good |
| SMS 业务先发后存（防止脏数据）| ✓ Good |
| 全项目时间统一为 DateTime.Now（北京时间）| ✓ Good |
| 微信小程序凭证 IOptions 注入代替硬编码 | ✓ Good |
| HttpClient 使用 IHttpClientFactory 代替裸注入 | ✓ Good |

### 已解决问题

- SMS 发送无超时导致请求永久挂起（已设 15s 超时）
- 验证码先入 DB 后发短信导致脏数据（改为先发后存）
- 验证码校验并发双花（ExecuteUpdateAsync 原子性更新）
- 阿里云短信手动 HMAC-SHA256 签名兼容性问题（替换为官方 SDK）
- 微信 AppSecret 硬编码泄露风险（迁移至 appsettings.json）
- UserAppService 裸 HttpClient 导致 Socket 泄漏（IHttpClientFactory）
- setInterval 泄漏导致内存不断增长（tabbar/index.vue）
- 5 处空 catch 块导致异常静默吞没
