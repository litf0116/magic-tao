## 🎨 设计原则

### 1. 游戏化设计
- 使用游戏风格的视觉元素
- 保留装备的稀有度颜色标识（普通=白，优秀=绿，精良=蓝，传说=橙，史诗=紫）
- 展示装备图标和等级标识
- 悬浮时显示属性预览

### 2. 信息层次
- **第一层**: 装备名称、图标、等级、品质
- **第二层**: 核心属性（攻击、防御）
- **第三层**: 详细属性、特殊效果
- **第四层**: 合成配方、掉落位置

### 3. 快速操作
- 支持键盘快捷键（↑↓选择，Enter查看详情，ESC关闭）
- 支持拖拽添加到对比
- 支持右键菜单（详情、对比、收藏）

### 4. 响应式设计
- PC端：充分利用屏幕空间，多列展示
- 移动端：单列卡片式布局，底部导航

## 🔍 搜索与筛选

### 搜索框设计

**位置**: 顶部固定或列表上方

**功能**:
- 实时搜索（输入时自动过滤）
- 支持装备名称、描述、属性关键词
- 搜索历史记录（最近10条）
- 热门搜索推荐

**PC端示例**:
```
┌─────────────────────────────────────────────────────────────┐
│ 🔍 搜索装备...                           [历史▼] [清除]  │
└─────────────────────────────────────────────────────────────┘
```

**移动端示例**:
```
┌──────────────────────────────────┐
│ 🔍 输入装备名称、类型...  [×]    │
└──────────────────────────────────┘
   热门搜索:
   [威力短弓] [亡灵铠甲] [火风水晶]
```

### 筛选器设计

**布局**:
- PC端: 侧边栏展开式筛选
- 移动端: 底部弹出式筛选面板

**筛选条件**:

#### 1. 装备类型（单选）
```
类型: [全部 ▼]
  ○ 全部
  ○ 武器
  ○ 防具
  ○ 首饰
  ○ 属性水晶
```

#### 2. 子类型（多选）
```
子类型: [剑类] [杖类] [枪类] [+选择]
```

#### 3. 装备等级（范围）
```
等级: [1] ━━━━━○━━━ [9]
     最小值: [1] 最大值: [9]
```

#### 4. 装备品质（多选）
```
品质: [普通] [优秀] [精良] [传说] [史诗]
```

#### 5. 属性筛选（范围）
```
攻击力: [0] ━━━━━○━━━ [999]
防御力: [0] ━━━━━○━━━ [999]
```

**快速筛选标签**:

### 2. 手势支持

- 下拉刷新（更新装备列表）
- 上拉加载更多
- 左滑查看详情
- 右滑收藏
- 长按显示菜单

### 3. 底部导航栏

## ♿ 可访问性

### 1. 键盘导航

- Tab键: 在元素间移动
- 方向键: 在列表中导航
- Enter/Space: 激活按钮/链接
- Escape: 关闭弹窗

### 2. 屏幕阅读器支持

- 装备图标添加 `alt` 属性
- 按钮添加 `aria-label`
- 表格添加 `caption`
- 对比添加 `aria-live`

### 3. 色彩对比度

- 文本与背景对比度 ≥ 4.5:1
- 大文本对比度 ≥ 3:1
- 不仅使用颜色传达信息（使用图标+颜色）

### 4. 字体大小

- 最小字体: 12px
- 推荐字体: 14-16px
- 重要信息: 18-24px

## 🎯 交互细节

### 1. 加载状态

- 骨架屏加载（展示占位内容）
- 列表懒加载（滚动时加载更多）
- 图片渐进式加载

### 2. 空状态

- 无搜索结果: 显示空状态图 + 提示
- 无装备数据: 显示引导 + 添加链接
- 网络错误: 显示重试按钮

### 3. 反馈机制

- 成功操作: Toast提示
- 错误操作: 错误提示 + 重试
- 加载中: 进度条或旋转图标

### 4. 动画效果

- 页面切换: 淡入淡出 (300ms)
- 列表加载: 依次淡入 (100ms 间隔)
- 按钮点击: 缩放效果 (200ms)
- 卡片悬浮: 上浮 + 阴影 (300ms)

## 📊 性能优化建议

### 1. 图片优化

- 使用 WebP 格式
- 响应式图片（提供多种尺寸）
- 懒加载（滚动到可视区域才加载）
- 图片CDN加速

### 2. 列表虚拟化

- 长列表使用虚拟滚动
- 只渲染可见区域的元素
- 复用DOM节点

### 3. 缓存策略

- 装备列表缓存（5分钟）
- 装备详情缓存（10分钟）
- 静态资源缓存（1小时）

### 4. 代码分割

- 按路由懒加载页面
- 按功能分割组件
- 异步加载非关键资源
