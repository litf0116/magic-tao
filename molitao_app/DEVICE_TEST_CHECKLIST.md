## 🛠️ 常见问题处理

### 问题1: 设备一直未授权
**解决方案**:
1. 在设备上：设置 → 开发者选项 → 撤销USB调试授权
2. 拔掉USB重新连接
3. 重新授权

### 问题2: 应用安装失败
**解决方案**:
```bash
# 清理构建缓存
flutter clean
flutter pub get

# 重新构建
flutter build apk --release
```

### 问题3: 应用闪退
**解决方案**:
```bash
# 查看日志
flutter logs -d 827af65d0722

# 或使用adb
adb logcat | grep -i flutter
```

### 问题4: 无法连接设备
**解决方案**:
1. 重启ADB服务：
```bash
adb kill-server
adb start-server
```
2. 检查USB线是否正常
3. 尝试不同的USB端口
