# Android设备兼容性测试操作指南

## 🚀 快速开始

### 1. 启动应用
```bash
# 在 molitao_app 目录下运行
flutter run -d chrome
```

### 2. 打开Device Preview
- 应用启动后，在右下角找到Device Preview按钮（手机图标）
- 点击打开设备选择面板

### 3. 选择测试设备
在设备列表中选择以下Android设备：
- **Small Phone** (360x640) - 小屏测试
- **Medium Phone** (412x915) - 中屏测试  
- **Large Phone** (412x915) - 大屏测试

## 📱 测试顺序和优先级

1. **Medium Phone** (412x915) - 主力设备

### 🥈 第二优先级（推荐测试）
