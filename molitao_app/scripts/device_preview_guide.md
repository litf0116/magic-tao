# Device Preview 使用指南

## 📱 功能介绍

Device Preview 是一个强大的 Flutter 开发工具，可以在开发过程中实时预览应用在不同设备上的显示效果，无需实际设备或模拟器。

## 🚀 快速开始

### 1. 安装依赖
```bash
# 依赖已添加到 pubspec.yaml
flutter pub get
```

### 2. 启动应用
```bash
# 启动应用，Device Preview 自动启用
flutter run -d chrome  # Web端效果最佳
flutter run -d macos   # macOS端
flutter run            # 默认设备
```

## 🛠️ 使用方法

### 1. 设备切换
- 在应用右侧或底部找到 Device Preview 面板
- 点击设备列表选择不同尺寸设备
- 支持实时切换，无需重启应用

### 2. 支持的测试设备

#### Android设备
- **Small Android**: 360x640 (小屏手机)
- **Pixel 4a**: 392.72x850.9 (Android小屏)
- **Pixel 6**: 412x915 (Android中屏)
- **Pixel 7 Pro**: 412x915 (Android大屏)
- **Tablet**: 1024x768 (平板)
- **Foldable**: 600x800 (折叠屏)

#### iOS设备
- **iPhone SE**: 320x568 (小屏)
- **iPhone 11**: 414x896 (中屏)

### 3. 功能特性

#### 实时调整
- **尺寸调整**: 拖动边框改变设备尺寸
- **旋转**: 点击旋转按钮测试横竖屏
- **缩放**: 使用滑块调整预览缩放比例

#### 调试工具
- **截图**: 点击截图按钮保存当前界面
- **标尺**: 显示尺寸参考线
- **网格**: 显示布局网格

#### 系统设置
- **主题**: 切换亮色/暗色模式
- **语言**: 切换不同语言环境
- **字体大小**: 调整系统字体大小

## 🐛 常见问题

### 1. Device Preview不显示
- 确保在 `main.dart` 中正确配置了 `DevicePreview`
- 检查是否启用了 `enabled: true`

### 2. 性能问题
- Device Preview会增加渲染负担，正式发布时请禁用
- 在性能测试时建议使用真实设备

### 3. 布局异常
- 使用 Flutter Inspector 调试具体布局问题
- 检查是否使用了固定尺寸而不是响应式布局

## 📝 禁用Device Preview

```dart
// 发布前禁用Device Preview
DevicePreview(
  enabled: false, // 改为false
  builder: (context) => ProviderScope(child: MyApp()),
)
```
