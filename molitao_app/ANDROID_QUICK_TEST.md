## 🔧 使用步骤

1. **启动测试**:
   ```bash
   ./scripts/quick_android_test.sh
   ```

2. **选择设备**:
   - 在右侧Device Preview面板中
   - 选择"Android设备"分类
   - 依次测试不同尺寸设备

3. **重点关注**:
   - **Pixel 6** (中屏) - 主力测试设备
   - **Small Android** (小屏) - 边缘情况
   - **Pixel 4a** (小屏) - 常见设备

4. **测试内容**:
   - 每个页面的布局适配
   - 主要功能的可用性
   - 交互元素的响应性

## 📊 测试标准

### 通过标准
- 所有核心功能正常工作
- 布局无截断或重叠
- 交互元素易于点击
- 性能无明显问题

### 优化建议
- 小屏设备关注字体大小
- 中屏设备为标准参考
- 大屏设备注意空间利用

## 🚀 快速测试流程
