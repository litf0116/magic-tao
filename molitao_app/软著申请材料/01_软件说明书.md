# 1. 软件概述

## 1.1 软件背景

随着移动互联网的快速发展，二手物品交易市场呈现出蓬勃发展的态势。传统的二手交易方式存在信息不对称、交易安全性低、沟通成本高等问题。用户需要一个操作便捷、实时交易、安全保障的移动应用平台来解决这些痛点。

魔力淘正是在这一市场需求下诞生的二手物品交易移动应用，致力于为用户提供便捷、安全、高效的二手物品交易体验。

## 1.2 软件定位

魔力淘是一款基于Flutter框架开发的二手物品交易移动应用，主要面向有二手物品交易需求的用户群体。软件集成了商品展示、在线交易、即时通讯、在线拍卖等功能模块，为用户提供一站式的二手物品交易服务。

## 1.3 主要特点

### 1.3.1 操作便捷

软件采用简洁直观的用户界面设计，用户可以快速上手。通过分类浏览、关键词搜索、热门推荐等多种方式，用户能够迅速找到所需的商品信息。发布商品流程简化，只需几步即可完成商品上架。

### 1.3.2 实时交易

软件支持在线拍卖功能，用户可以实时参与竞拍。拍卖过程中系统实时更新竞价信息，确保交易公平透明。同时支持即时通讯功能，买卖双方可以实时沟通，协商交易细节。

### 1.3.3 安全保障

软件采用魔力值（保证金）制度，用户需缴纳一定金额的保证金才能参与交易和发布商品，有效降低交易风险。同时提供用户认证机制，确保交易双方身份的真实性。

### 1.3.4 即时通讯

内置即时通讯模块，支持一对一私聊和群聊功能。用户可以在交易过程中实时沟通，解决交易疑问，提高交易成功率。

# 2. 功能介绍

## 2.1 用户认证模块

### 2.1.1 登录注册

用户可以通过以下方式完成登录注册：

**账号密码登录：** 用户输入注册的手机号和密码即可登录。系统支持记住用户名功能，下次登录时自动填充。

**短信验证码登录：** 用户输入手机号，获取短信验证码后即可登录。验证码有效期为60秒。

**微信登录：** 软件集成微信登录功能，用户可通过微信快速授权登录，提升登录体验。

### 2.1.2 账户安全

软件提供账户安全相关功能：

- 修改密码：用户可在设置中修改登录密码
- 绑定手机号：用户需绑定手机号用于登录和找回密码
- 账户注销：用户可申请注销账户

### 2.1.3 用户状态管理

软件采用Riverpod状态管理框架管理用户登录状态。用户状态包括：

- 登录状态（是否已登录）
- 用户信息（ID、用户名、昵称、头像等）
- 魔力值余额
- 用户权限和角色

## 2.2 首页模块

### 2.2.1 Banner轮播图

首页顶部展示Banner轮播图，自动轮播展示重要活动和内容。Banner图片从服务器动态获取，支持点击跳转。

### 2.2.2 广告位

首页包含广告位模块，展示各类促销信息和商品推荐。广告位采用网格布局，支持图片展示和标题显示。

### 2.2.3 文章资讯

文章资讯模块展示平台发布的各类文章内容，包括使用教程、交易指南、活动公告等。用户可点击文章查看详细内容。

### 2.2.4 功能入口

首页提供快速功能入口，包括：

- 交易站入口：跳转至商品列表页
- 拍卖场入口：跳转至在线拍卖页

## 2.3 交易站模块

### 2.3.1 商品列表

交易站模块展示所有发布的商品信息。用户可以：

- 浏览全部商品
- 按分类筛选商品
- 搜索商品关键词
- 查看热门搜索词

商品列表采用分页加载机制，支持下拉刷新和上拉加载更多。

### 2.3.2 商品详情

点击商品进入详情页，展示内容包括：

- 商品图片轮播
- 商品标题和价格
- 商品详细描述
- 发布者信息
- 发布时间

用户可在详情页发起聊天或直接购买。

### 2.3.3 商品发布

用户可发布二手商品，填写信息包括：

- 商品标题
- 商品分类
- 商品价格
- 商品描述
- 商品图片（最多9张）
- 热门关键词标签

发布商品需缴纳魔力值保证金。

### 2.3.4 公告栏

交易站顶部显示平台公告，内容以HTML格式渲染，支持富文本展示。

## 2.4 即时通讯模块

### 2.4.1 会话列表

会话列表页面展示所有聊天会话，包括：

- 私聊会话：与单个用户的对话
- 群聊会话：多人参与的群组对话
- 系统会话：系统通知和公告

会话列表显示未读消息数量，支持左滑删除会话。

### 2.4.2 私聊功能

用户可与商品发布者或其他用户进行一对一私聊。聊天功能包括：

- 发送文本消息
- 发送图片消息
- 发送系统消息（如出价、成交等）
- 聊天记录保存

### 2.4.3 群聊功能

软件支持多种群聊功能：

- 新手群聊：新手用户交流群
- 群组聊天：用户可创建或加入群组

### 2.4.4 在线拍卖

即时通讯模块集成在线拍卖功能：

- 拍卖场：展示正在进行的拍卖活动
- 实时竞价：用户可对商品进行出价

- 拍卖历史：查看历史拍卖记录

## 2.5 支付模块

### 2.5.1 保证金充值

用户需充值魔力值（保证金）才能参与交易和发布商品。魔力值充值通过PC端完成，移动端展示充值引导。

提现功能正在完善中。用户需联系管理员进行魔力值提现操作。

通讯录页面展示用户的好友列表。用户可通过搜索添加好友。

# 3. 软件架构

## 3.1 技术架构

### 3.1.1 Flutter框架

魔力淘采用Flutter作为主要开发框架。Flutter是Google推出的跨平台UI框架，支持iOS和Android双平台开发，具有以下优势：

- 高性能的渲染引擎：使用Skia图形引擎，提供流畅的UI体验
- 丰富的组件库：提供大量可定制的UI组件
- 热重载功能：支持开发时快速预览修改效果
- 跨平台一致性：同一套代码在iOS和Android上呈现一致的UI效果

### 3.1.2 Dart语言

软件主要编程语言为Dart。Dart是Google开发的面向对象编程语言，具有以下特点：

- 类型安全：支持静态类型检查，减少运行时错误
- 空安全：内置空安全机制，避免空指针异常
- 高性能：支持JIT和AOT两种编译方式
- 丰富的标准库：提供常用的数据结构和工具类

### 3.1.3 Riverpod状态管理

软件采用Riverpod作为状态管理解决方案。Riverpod是Flutter生态中流行的状态管理库，具有以下特点：

- 编译时安全：状态提供者在编译时进行检查
- 易于测试：状态可独立于UI进行测试
- 依赖注入：内置依赖注入机制
- 响应式编程：基于Stream和Future的响应式编程模型

### 3.1.4 GoRouter路由管理

软件采用GoRouter作为路由管理方案。GoRouter是Flutter官方推荐的路由库，支持：

- 声明式路由：基于配置的路由定义
- 深层链接：支持URL直接访问特定页面
- 路由守卫：支持登录状态验证和重定向
- 路径参数：支持动态路径参数

## 3.2 模块划分

### 3.2.1 目录结构

软件采用清晰的分层目录结构：

```
lib/
├── core/                    # 核心模块
│   ├── router/              # 路由配置
│   ├── theme/               # 主题配置
│   └── utils/               # 工具类
├── data/                    # 数据层
│   ├── api/                 # API客户端
│   ├── models/              # 数据模型
│   ├── repositories/        # 数据仓库
│   └── services/            # 业务服务
├── domain/                  # 领域层
│   └── entities/            # 领域实体
├── presentation/            # 表现层
│   ├── mixins/              # Mixin类
│   ├── pages/               # 页面组件
│   ├── providers/            # 状态提供者
│   └── widgets/             # 公共组件
├── app.dart                 # 应用入口
└── main.dart               # 程序入口
```

### 3.2.2 核心模块

**core模块：** 包含应用的核心配置和工具类

- router：路由配置文件
- theme：主题和颜色配置
- utils：通用工具类

**data模块：** 包含数据相关的类和接口

- api：网络请求客户端和相关配置
- models：数据模型类
- repositories：数据仓库，封装数据操作逻辑
- services：业务服务类

**domain模块：** 包含领域实体类

- entities：领域实体定义

**presentation模块：** 包含UI相关的类和组件

- mixins：Mixin类，封装可复用的逻辑
- pages：页面组件，每个页面一个文件
- providers：状态提供者，定义应用状态
- widgets：公共组件，可在多个页面复用

## 3.3 后端服务架构

### 3.3.1 API架构

软件通过RESTful API与后端服务器通信。API客户端采用Dio网络库，配置了以下功能：

- 请求拦截器：统一添加认证Token
- 响应拦截器：统一处理错误响应
- 超时配置：设置请求和响应超时时间

### 3.3.2 WebSocket通信

即时通讯功能采用WebSocket协议实现实时通信。WebSocket服务提供以下功能：

- 消息实时推送
- 会话状态同步
- 拍卖竞价实时更新

### 3.3.3 数据存储

软件采用以下数据存储方案：

- 本地存储：使用shared_preferences存储用户偏好设置
- 内存缓存：使用Riverpod缓存API响应数据
- 图片缓存：使用cached_network_image缓存网络图片

# 5. 使用说明

## 5.1 首次使用

### 5.1.1 下载安装

用户可通过以下渠道下载安装魔力淘：

- Android用户：从应用商店或官网下载APK安装
- iOS用户：从App Store搜索"魔力淘"下载安装

### 5.1.2 用户注册

首次使用时，用户需完成注册：

1. 打开应用，进入登录页面
2. 点击"注册"按钮进入注册页面
3. 填写手机号、验证码、密码等信息
4. 阅读并同意《用户协议》
5. 点击"注册"完成注册

### 5.1.3 首次登录

注册完成后，用户可选择以下方式登录：

**账号密码登录：**

1. 输入注册的手机号
2. 输入密码
3. 点击"登录"

**短信验证码登录：**

1. 输入手机号
2. 点击"获取验证码"
3. 输入收到的短信验证码
4. 点击"登录"

**微信登录：**

1. 点击微信登录图标
2. 在微信中确认授权
3. 完成登录

## 5.2 购买商品流程

### 5.2.1 浏览商品

用户可通过以下方式浏览商品：

1. **首页推荐：** 在首页查看热门商品和推荐商品
2. **分类浏览：** 进入交易站，选择分类浏览商品
3. **搜索商品：** 在搜索框输入关键词搜索商品

### 5.2.2 查看详情

点击商品进入详情页，查看：

- 商品图片
- 商品价格
- 商品描述
- 发布者信息

### 5.2.3 联系卖家

在商品详情页，用户可点击"联系卖家"按钮，与卖家进行私聊沟通。

### 5.2.4 参与拍卖

对于拍卖商品，用户可参与竞拍：

1. 进入拍卖场页面
2. 选择感兴趣的拍卖商品
3. 输入出价金额
4. 确认出价

## 5.3 发布商品流程

### 5.3.1 准备工作

发布商品前，用户需：

1. 确保已登录账号
2. 确认魔力值余额充足（需缴纳保证金）

### 5.3.2 填写商品信息

1. 进入交易站页面
2. 点击"发布"按钮
3. 填写商品信息：

   - 商品标题（必填）
   - 商品分类（必填）
   - 商品价格（必填）
   - 商品描述（必填）
   - 商品图片（必填，最多9张）
   - 热门关键词（选填）

4. 检查信息无误后，点击"发布"

### 5.3.3 等待审核

商品发布后需经过审核，审核通过后即可在交易站展示。

## 5.4 即时通讯使用

### 5.4.1 发送消息

在私聊或群聊页面，用户可：

1. 在输入框输入文字消息
2. 点击发送按钮发送消息
3. 支持发送图片消息

### 5.4.2 消息类型

软件支持多种消息类型：

- 文本消息：普通文字消息
- 图片消息：发送本地图片
- 系统消息：交易、出价等系统通知

### 5.4.3 群聊功能

用户可参与以下群聊：

- **大厅：** 所有用户可参与的自由聊天
- **新手群：** 新手用户交流群
- **自定义群组：** 用户可创建或加入兴趣群组
