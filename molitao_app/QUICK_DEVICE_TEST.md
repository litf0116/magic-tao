# 快速设备兼容性测试指南

## 🚀 一键启动 Device Preview

```bash
# 运行测试脚本
./scripts/run_device_preview.sh
```

## 📱 支持的测试设备

### Android设备
- **Small Android**: 360x640 (小屏手机)
- **Pixel 4a**: 392.72x850.9 (Android小屏)
- **Pixel 6**: 412x915 (Android中屏)
- **Pixel 7 Pro**: 412x915 (Android大屏)
- **Tablet**: 1024x768 (平板)
- **Foldable**: 600x800 (折叠屏)

### iOS设备
- **iPhone SE**: 320x568 (小屏)
- **iPhone 11**: 414x896 (中屏)

## 🎯 测试重点

### 1. 布局适配
- 检查首页在不同尺寸下的显示效果
- 验证底部导航栏在所有尺寸下可见
- 确保聊天界面消息气泡适配良好
- 测试表单输入区域不被键盘遮挡

### 2. 功能测试
- 验证所有页面可以正常导航
- 检查图片在不同尺寸下正确显示
- 确保按钮点击区域足够大
- 测试列表滚动流畅性

### 3. 性能观察
- 观察不同尺寸下的渲染性能
- 检查启动时间在可接受范围内
- 验证页面切换无卡顿

## 🔧 使用技巧

### 1. 快速切换设备
- 在Device Preview面板中直接选择设备
- 使用快捷键 `Cmd/Ctrl + Shift + P` 快速打开面板
- 实时切换设备无需重启应用

### 2. 调试工具
- **截图**: 点击截图按钮保存当前界面
- **旋转**: 测试横竖屏适配
- **缩放**: 调整预览缩放比例
- **主题**: 切换亮色/暗色模式

### 3. 边缘测试
- 重点关注小屏设备(iPhone SE)的布局适配
- 测试大屏设备(Tablet)的空间利用
- 验证折叠屏设备的特殊布局需求

## 🐛 常见问题解决

### 1. Device Preview不显示
- 确保已运行 `flutter pub get`
- 检查main.dart中DevicePreview配置正确

### 2. 性能问题
- Device Preview会增加渲染负担，这是正常现象
- 正式发布版本会自动禁用Device Preview

### 3. 布局异常
- 使用Flutter Inspector调试具体布局问题
- 避免使用固定尺寸，改用响应式布局

## 📝 发布前禁用

```dart
// 发布前将enabled改为false
DevicePreview(
  enabled: false, // 改为false
  builder: (context) => ProviderScope(child: MyApp()),
)
```
