【软件全称】：魔力淘App
【软件简称】：魔力淘
【版本号】：V1.0
【软件完成日期】：2026-05-01
【开发的硬件环境】：Intel Core i5处理器，16GB内存，512GB固态硬盘
【运行的硬件环境】：客户端：Android设备不少于3GB内存，iOS设备不少于2GB内存，存储空间不少于200MB；服务端：内存8GB及以上，存储空间100GB及以上
【开发该软件的操作系统】：Windows 11 / macOS Sonoma
【软件开发环境 / 开发工具】：Android Studio、VS Code、Flutter SDK 3.x、Dart SDK 3.x、Xcode（iOS构建）
【该软件的运行平台 / 操作系统】：Android 8.0及以上 / iOS 12.0及以上
【软件运行支撑环境 / 支持软件】：MySQL、Redis、Nginx、ASP.NET Core后端服务
【编程语言】：Dart
【源程序量】：23,501
【开发目的】：为用户提供便捷、高效的在线撮合平台，帮助用户发现闲置物品、在线沟通协商，促进资源流通。平台仅提供信息撮合服务，交易由用户自行线下完成，不提供交易担保。
【面向领域 / 行业】：分类信息 / 社交电商
【软件的主要功能】：魔力淘App是一款在线撮合平台移动应用，主要功能包括：1. 用户模块：支持账号密码注册登录、微信一键登录、个人资料管理。2. 帖子模块：帖子浏览与分类筛选、帖子详情查看、帖子发布功能。3. 撮合模块：即时通讯、消息推送、秒杀场实时聊天。4. 支付模块：余额充值、提现（平台代收代付性质，非交易担保）。5. 个人中心：资产管理、好友管理、订单查询。6. 其他功能：设置与偏好配置、意见反馈、公告查看。
【软件的技术特点选项】：移动应用软件
【技术特点】：基于Flutter跨平台框架开发，采用Riverpod状态管理、GoRouter路由管理，支持Android与iOS双平台；后端采用ASP.NET Core与ABP Framework微服务架构，MySQL数据库存储，WebSocket实现实时通讯，具有跨平台一致性、高性能渲染、模块化架构的技术优势。
【软件分类】：应用软件
