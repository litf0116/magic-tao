1. 软件概述

魔力淘App是一款闲置物品信息撮合平台移动应用，为用户提供便捷的闲置物品信息浏览、发布、在线沟通等功能。用户可以通过本应用发布闲置物品信息、浏览他人发布的物品、通过平台内置即时通讯工具与对方在线协商，交易由用户自行线下完成，平台不提供交易担保。

主要功能： - 帖子浏览与搜索 - 闲置物品信息发布与管理 - 即时消息通讯 - 好友关系管理 - 余额充值与提现（代收代付，非交易担保） - 个人信息管理 - 系统公告查看 - 秒杀人气活动参与

平台性质声明： 本平台仅为用户提供信息发布与在线沟通撮合服务，物品交易由用户自行线下完成。平台不参与交易环节，不提供交易担保，不对交易产生的任何纠纷承担责任。

技术架构： - 前端：Flutter 跨平台移动应用框架 - 后端：C# .NET 8 + ABP Framework - 数据库：MySQL - 即时通讯：WebSocket

2. 运行环境

2.1 Android系统要求

  • 操作系统：Android 8.0 及以上版本
  • 存储空间：至少100MB可用空间
  • 网络：需要网络连接（Wi-Fi或移动数据）

2.2 iOS系统要求

  • 操作系统：iOS 12.0 及以上版本
  • 存储空间：至少100MB可用空间
  • 网络：需要网络连接（Wi-Fi或移动数据）

3. 安装说明

3.1 Android安装

  1. 从应用市场下载安装包
  2. 点击安装包进行安装
  3. 安装完成后点击图标启动应用
  4. 首次启动需要授予网络权限

3.2 iOS安装

  1. 从App Store搜索”魔力淘”
  2. 点击”获取”按钮下载安装
  3. 安装完成后点击图标启动应用

4. 功能模块说明

4.1 首页模块

功能描述：首页是用户进入应用后的第一个界面，展示平台品牌形象、功能入口、内容资讯等。

界面元素： - 平台品牌展示与 Banner 广告 - 交易站快速入口（跳转交易帖子列表） - 秒杀场快速入口（跳转秒杀聊天页面） - CMS 文章轮播展示 - 广告位网格展示 - APP 版本更新检测与弹窗提示

操作说明： 1. 点击 Banner 广告查看推广内容 2. 点击交易站入口浏览商品帖子 3. 点击秒杀场入口参与实时交易 4. 滑动查看轮播文章内容 5. 系统自动检测版本更新

4.2 认证登录模块

功能描述：认证登录模块提供多种登录方式，支持账号密码、短信验证码、微信一键登录等。

界面元素： - 用户名密码输入框 - 手机号码输入框 - 验证码输入框 - 微信登录按钮 - 记住账号选项 - 二维码扫码登录入口

操作说明： 1. 账号密码登录：输入用户名和密码，点击登录按钮 2. 短信验证码登录：输入手机号，点击获取验证码，输入收到的验证码登录 3. 微信一键登录：点击微信图标，授权后自动登录 4. 二维码登录：点击扫码图标，用微信扫描二维码确认登录 5. 登录成功后自动跳转目标页面

4.3 交易帖子模块

功能描述：撮合帖子模块是核心业务模块，用户可发布、浏览、管理闲置物品信息帖，实现供需双方的信息撮合。

4.3.1 交易站（帖子列表）

功能描述：交易站展示平台所有撮合帖子信息，用户可按分类浏览、搜索感兴趣的内容。

界面元素： - 分类标签筛选（交易/求购/问答/分享/其他） - 搜索框 + 热搜词快捷搜索 - 置顶帖子区域展示 - 帖子卡片列表 - 发布帖子按钮

操作说明： 1. 点击分类标签筛选帖子类型 2. 在搜索框输入关键词搜索 3. 点击热搜词快速搜索热门内容 4. 下拉刷新获取最新帖子 5. 上拉加载更多帖子 6. 点击发布按钮创建新帖子

4.3.2 帖子详情页

功能描述：帖子详情页展示物品信息的完整内容，用户可查看详情并通过内置通讯工具联系发布者进行在线协商。

界面元素： - 帖子标题、作者信息、发布时间 - 联系方式展示（微信、QQ） - 分类标签展示 - 富文本内容展示 - 图片预览功能 - 联系对方按钮（跳转私聊） - 编辑/删除按钮（仅作者可见）

操作说明： 1. 查看帖子完整内容和图片 2. 点击图片放大预览 3. 点击"联系对方"跳转私聊进行在线协商 4. 作者可点击编辑修改帖子 5. 作者可点击删除移除帖子 6. 交易由双方自行线下完成，平台不参与

4.3.3 发布帖子页

功能描述：用户可通过发布帖子功能，将闲置物品信息发布到平台，等待有意向的用户联系。

界面元素： - 标题输入框（最多100字） - 分类选择器 - 内容编辑器（支持富文本） - 图片上传区域 - 联系方式填写（微信、QQ） - 发布按钮

操作说明： 1. 输入帖子标题 2. 选择帖子分类 3. 编辑帖子内容，可插入图片 4. 上传物品图片（支持多张） 5. 填写联系方式（可选） 6. 点击发布提交帖子

4.4 即时通讯模块

功能描述：即时通讯模块提供实时聊天功能，支持私聊、群聊、秒杀场等场景。

4.4.1 会话列表

界面元素： - 会话列表（头像、名称、最新消息、时间） - 未读消息红点提示 - 特殊频道入口（系统公告、新手群、秒杀场） - 消息类型区分图标

操作说明： 1. 点击会话进入聊天界面 2. 查看未读消息数量 3. 长按会话可删除聊天记录 4. 点击特殊频道进入群聊

4.4.2 私聊界面

界面元素： - 聊天消息气泡 - 消息输入框 - 表情选择器 - 图片发送按钮 - 对方头像和昵称

操作说明： 1. 输入文字消息发送 2. 点击图片按钮发送图片 3. 点击表情选择器发送表情 4. 上拉加载历史消息 5. 点击对方头像查看资料

4.4.3 群聊界面

功能描述：群聊界面支持多人同时在线交流，适用于秒杀场、兴趣群组等场景。

界面元素： - 群成员头像展示 - 实时消息滚动 - 输入框和发送按钮 - 表情和图片发送

操作说明： 1. 进入群聊查看历史消息 2. 发送文字、图片、表情消息 3. 查看在线成员列表 4. 点击成员头像查看资料

4.4.4 秒杀场

功能描述：秒杀场是平台的限时特惠活动专区，用户可以参与商品的超值优惠活动。

界面元素： - 限时秒杀商品展示 - 当前秒杀状态（进行中/已结束） - 下单区域 - 秒杀动态实时滚动 - 公告通知栏 - 商品详情弹窗

操作说明： 1. 查看当前秒杀商品信息和价格 2. 点击”立即秒杀”参与活动 3. 查看实时下单动态 4. 点击商品查看详情 5. 秒杀成功跳转支付页面

4.5 通讯录模块

功能描述：通讯录模块管理好友关系，支持添加好友、处理好友申请等操作。

界面元素： - 好友搜索框 - 好友申请列表 - 好友列表 - 好友状态标识

操作说明： 1. 搜索框输入昵称查找好友 2. 查看好友申请列表 3. 同意或拒绝好友申请 4. 点击好友发起私聊

4.6 个人中心模块

功能描述：个人中心模块管理用户个人信息、资产、订单等。

4.6.1 个人中心主页

界面元素： - 用户信息卡片（头像、昵称、编号） - 统计数据（好友数、余额） - 工作台入口 - 买家功能区（我的订单、我的收藏） - 卖家功能区（我发布的、保证金记录） - 设置入口 - APP 版本号

操作说明： 1. 点击头像编辑个人信息 2. 查看好友数量和账户余额 3. 进入工作台管理资产（充值、提现、余额明细） 4. 点击功能区快速访问对应页面

4.6.2 个人信息编辑

界面元素： - 用户编号展示 - 头像上传区域 - 昵称输入框 - QQ 号输入框 - 微信号输入框 - 保存按钮

操作说明： 1. 点击头像更换头像 2. 修改昵称 3. 填写或修改 QQ 号 4. 填写或修改微信号 5. 点击保存提交修改

4.6.3 工作台（资产中心）

功能描述：工作台提供账户资产管理功能，包括余额查询、充值、提现、保证金管理、交易记录查询等。

界面元素： - 当前余额展示 - 充值按钮 - 提现按钮 - 保证金记录入口 - 余额明细入口 - 交易记录列表

操作说明： 1. 查看当前账户余额 2. 点击充值，跳转微信支付进行充值 3. 点击提现，申请提现到绑定账户 4. 查看保证金缴纳记录 5. 查看余额收支明细 6. 查看交易记录

4.7 公告模块

功能描述：公告模块展示平台公告和通知，包括系统公告、活动通知等。

界面元素： - 公告列表 - 分类筛选（系统公告、活动通知） - 公告图片预览 - 发布时间展示

操作说明： 1. 浏览公告列表 2. 点击分类筛选公告 3. 点击公告查看详情 4. 下拉刷新获取最新公告

4.8 设置模块

功能描述：设置模块提供应用基础配置功能，包括推送通知、清除缓存、版本信息等。

界面元素： - 推送通知开关 - 清除缓存按钮 - 缓存大小显示 - 版本信息展示 - 用户协议链接 - 退出登录按钮

操作说明： 1. 开启/关闭推送通知 2. 点击清除缓存释放存储空间 3. 查看当前应用版本号 4. 点击用户协议阅读相关规定 5. 点击退出登录安全退出账号

4.9 账号安全模块

功能描述：账号安全模块提供账号安全相关设置，包括修改密码、绑定微信、绑定手机号等。

界面元素： - 当前登录方式展示 - 修改密码入口 - 绑定微信入口 - 绑定手机号入口 - 账号安全提示

操作说明： 1. 查看当前绑定的登录方式 2. 点击修改密码，设置新密码 3. 点击绑定微信，授权绑定微信账号 4. 点击绑定手机号，绑定或更换手机号 5. 根据提示完成安全验证

4.10 关于模块

功能描述：关于模块展示应用版本信息、用户协议、检查更新等功能。

界面元素： - 应用图标和名称 - 当前版本号 - 检查更新按钮 - 用户协议链接 - 隐私政策链接 - 联系方式

操作说明： 1. 查看当前应用版本信息 2. 点击检查更新，检测是否有新版本 3. 点击用户协议阅读相关条款 4. 点击隐私政策了解数据使用规则 5. 如有问题可联系官方客服

5. 操作流程说明

5.1 用户注册登录流程

  1. 下载安装：从应用市场下载并安装应用
  2. 启动应用：点击图标启动应用
  3. 选择登录方式：账号密码/短信验证码/微信登录/二维码登录
  4. 完成登录：输入凭证或授权后进入首页
  5. 完善信息：首次登录可完善个人资料

5.2 发布帖子流程

  1. 进入发布页：点击首页或个人中心发布按钮
  2. 填写信息：输入标题、选择分类、编辑内容
  3. 上传图片：选择或拍摄物品图片
  4. 填写联系方式：输入微信或 QQ 号（可选）
  5. 提交发布：点击发布按钮完成发布

5.3 撮合沟通流程

  1. 浏览帖子：在帖子列表浏览闲置物品信息
  2. 查看详情：点击帖子查看详细信息
  3. 联系对方：点击"联系对方"发起私聊
  4. 在线协商：通过聊天协商交易细节
  5. 线下成交：双方自行线下完成交易，平台不参与

5.3 交易沟通流程

  1. 浏览商品：在帖子列表浏览商品
  2. 查看详情：点击帖子查看详细信息
  3. 联系卖家：点击”联系对方”发起私聊
  4. 在线沟通：通过聊天协商交易细节
  5. 达成交易：双方确认后完成交易

5.4 充值提现流程

  1. 进入个人中心：点击底部导航个人中心
  2. 进入工作台：点击工作台入口
  3. 选择操作：点击充值或提现
  4. 输入金额：填写充值或提现金额
  5. 完成支付：跳转微信完成支付操作

5.5 账号安全设置流程

  1. 进入设置：从个人中心点击设置入口
  2. 进入账号安全：点击账号安全选项
  3. 选择操作：修改密码/绑定微信/绑定手机
  4. 完成验证：根据提示完成安全验证
  5. 确认成功：操作完成后显示成功提示

6. 常见问题

Q1：如何修改个人信息？ A：进入个人中心，点击头像进入个人信息编辑页面进行修改。

Q2：如何联系对方？ A：在帖子详情页点击”联系对方”按钮，进入聊天界面发送消息。

Q3：支付失败怎么办？ A：请检查网络连接和支付账户余额，重新尝试支付。如问题持续，请联系客服。

Q4：如何添加好友？ A：在通讯录页面搜索用户昵称，找到后点击添加好友按钮发送申请。

Q5：如何查看历史订单？ A：进入个人中心，在买家/卖家功能区可查看对应订单记录。

Q6：如何退出登录？ A：进入个人中心，点击设置，点击退出登录按钮。

Q7：忘记密码怎么办？ A：在登录页面选择短信验证码登录，登录后在账号安全中设置新密码。

Q8：如何绑定微信？ A：进入个人中心 > 设置 > 账号安全，点击绑定微信。

Q9：如何充值余额？ A：进入个人中心 > 工作台，点击充值，选择金额后跳转微信完成支付。

Q10：如何查看版本更新？ A：进入设置 > 关于，点击检查更新，系统会提示是否有新版本。
