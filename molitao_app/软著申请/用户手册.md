## 1. 软件概述

魔力淘是一款二手物品交易平台移动应用，为用户提供便捷的二手商品浏览、交易、支付等功能。用户可以通过本应用发布闲置物品、浏览他人发布的商品、参与交易、完成支付等操作。

**主要功能**：
- 商品浏览与搜索
- 交易帖子发布与管理
- 即时消息通讯
- 好友关系管理
- 在线支付
- 个人信息管理
- 系统公告查看

**技术架构**：
- 前端：Flutter 跨平台移动应用框架
- 后端：C# .NET 8 + ABP Framework
- 数据库：MySQL
- 即时通讯：WebSocket

## 2. 运行环境

### 2.1 Android系统要求

- **操作系统**：Android 8.0 及以上版本
- **存储空间**：至少100MB可用空间
- **网络**：需要网络连接（Wi-Fi或移动数据）

### 2.2 iOS系统要求

- **操作系统**：iOS 12.0 及以上版本
- **存储空间**：至少100MB可用空间
- **网络**：需要网络连接（Wi-Fi或移动数据）

## 5. 操作流程说明

### 5.1 用户注册登录流程

1. **下载安装**：从应用市场下载并安装应用
2. **启动应用**：点击图标启动应用
3. **选择登录方式**：账号密码/短信验证码/微信登录
4. **完成登录**：输入凭证或授权后进入首页
5. **完善信息**：首次登录可完善个人资料

### 5.2 发布商品流程

1. **进入发布页**：点击首页或个人中心发布按钮
2. **填写信息**：输入标题、选择分类、编辑内容
3. **上传图片**：选择或拍摄商品图片
4. **填写联系方式**：输入微信或 QQ 号（可选）
5. **提交发布**：点击发布按钮完成发布

### 5.3 交易沟通流程

1. **浏览商品**：在帖子列表浏览商品
2. **查看详情**：点击帖子查看详细信息
3. **联系卖家**：点击"联系对方"发起私聊
4. **在线沟通**：通过聊天协商交易细节
5. **达成交易**：双方确认后完成交易

### 5.4 充值提现流程

1. **进入个人中心**：点击底部导航个人中心
2. **进入工作台**：点击工作台入口
3. **选择操作**：点击充值或提现
4. **输入金额**：填写充值或提现金额
5. **完成支付**：跳转微信完成支付操作

## 6. 常见问题

**Q1：如何修改个人信息？**  
A：进入个人中心，点击头像进入个人信息编辑页面进行修改。

**Q2：如何联系卖家？**  
A：在商品详情页点击"联系对方"按钮，进入聊天界面发送消息。

**Q3：支付失败怎么办？**  
A：请检查网络连接和支付账户余额，重新尝试支付。如问题持续，请联系客服。

**Q4：如何添加好友？**  
A：在通讯录页面搜索用户昵称，找到后点击添加好友按钮发送申请。

**Q5：如何查看历史订单？**  
A：进入个人中心，在买家/卖家功能区可查看对应订单记录。

**Q6：如何退出登录？**  
A：进入个人中心，点击设置，点击退出登录按钮。

**Q7：忘记密码怎么办？**  
A：在登录页面选择短信验证码登录，登录后在账号安全中设置新密码。

**Q8：如何绑定微信？**  
A：进入个人中心 > 设置 > 账号安全，点击绑定微信。
