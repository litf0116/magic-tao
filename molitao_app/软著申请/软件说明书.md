## 第一章 软件概述

### 1.1 软件背景

随着移动互联网的快速发展，传统的拍卖交易模式正在向线上转移。「魔力淘」是一款专注于在线拍卖交易平台的移动应用，旨在为用户提供便捷的商品展示、竞价拍卖、聊天沟通等一站式服务。

### 1.2 软件定位

「魔力淘」定位为二手物品拍卖交易平台，用户可以通过手机便捷地发布商品、参与拍卖、与其他用户实时沟通。

### 1.3 主要特点

1. **操作便捷**：简洁直观的用户界面，降低使用门槛
2. **实时拍卖**：支持拍卖出价实时更新，保证交易时效性
3. **安全保障**：保证金机制，降低交易风险
4. **即时通讯**：内置聊天功能，方便买卖双方沟通

## 第二章 功能介绍

### 2.1 用户模块

#### 2.1.1 用户注册登录

用户可以通过以下方式注册和登录：
- **账号密码登录**：输入用户名和密码进行登录
- **微信一键登录**：通过微信授权快速登录，无需注册

#### 2.1.2 个人中心

用户可在个人中心管理：
- 个人资料（头像、昵称、联系方式）
- 账户余额查询
- 保证金管理
- 收藏商品
- 消息通知设置

### 2.2 商品模块

#### 2.2.1 商品列表

首页展示所有在售商品，支持：
- 按分类筛选
- 按价格排序
- 搜索商品名称

#### 2.2.2 商品详情

点击商品进入详情页，展示：
- 商品图片（支持多图浏览）
- 商品名称和描述
- 当前最高出价
- 拍卖结束时间
- 卖家信息

#### 2.2.3 商品发布

用户可以发布商品：
1. 拍摄/选择商品图片（最多9张）
2. 填写商品名称、描述
3. 设置起拍价格
4. 设置拍卖时长
5. 提交发布

### 2.3 拍卖模块

#### 2.3.1 拍卖参与

用户参与拍卖流程：
1. 选择感兴趣的商品
2. 阅读拍卖规则
3. 缴纳保证金
4. 输入出价金额
5. 确认出价

#### 2.3.2 拍卖状态

拍卖活动包含以下状态：
- **预告中**：拍卖即将开始
- **进行中**：用户可以出价
- **已结束**：拍卖时间到，等待结果确认
- **已成交**：最高出价者获得商品
- **已流拍**：无人出价或未达保留价

#### 2.3.3 出价记录

用户可查看商品的完整出价历史，包括：
- 出价时间
- 出价用户
- 出价金额

### 2.4 聊天模块

#### 2.4.1 私信功能

用户之间可以一对一私信沟通：
- 发送文字消息
- 发送图片
- 查看聊天记录

#### 2.4.2 群聊功能

支持拍卖群聊功能：
- 拍卖参与者群聊
- 实时出价通知推送
- 群公告查看

### 2.5 支付模块

#### 2.5.1 保证金充值

用户需缴纳保证金方可参与拍卖：
- 支持微信支付
- 固定保证金金额：51元
- 充值成功后即可参与拍卖出价

#### 2.5.2 余额提现

用户可将账户余额提现至银行卡：
- 输入提现金额
- 确认提现信息
- 等待审核处理

### 2.6 消息模块

#### 2.6.1 消息类型

系统推送以下类型消息：
- 拍卖出价通知
- 拍卖结果通知
- 私信消息
- 系统公告

#### 2.6.2 消息提醒

支持消息提醒设置：
- 声音提醒
- 震动提醒
- 免打扰时段

## 第三章 软件架构

### 3.1 技术架构

「魔力淘」采用 Flutter 跨平台框架开发，主要技术选型：

| 组件 | 技术方案 |
|-----|---------|
| 框架 | Flutter 3.x |
| 语言 | Dart 3.x |
| 状态管理 | Riverpod |
| 路由管理 | GoRouter |
| 网络请求 | Dio |
| 即时通讯 | WebSocket |
| 本地存储 | SharedPreferences |

### 3.2 模块划分

```
lib/
├── core/              # 核心模块
│   ├── router/        # 路由配置
│   └── theme/         # 主题配置
├── data/              # 数据层
│   ├── api/           # API 客户端
│   ├── models/         # 数据模型
│   └── repositories/   # 数据仓库
├── domain/            # 领域层
│   └── entities/       # 实体定义
├── presentation/       # 表现层
│   ├── pages/          # 页面
│   ├── providers/      # 状态管理
│   └── widgets/        # 通用组件
└── services/          # 服务层
```

## 第五章 使用说明

### 5.1 首次使用

1. 下载并安装应用
2. 打开应用，进入登录页面
3. 选择登录方式（账号密码/微信）
4. 登录成功后进入首页

### 5.2 参与拍卖

1. 在商品列表选择感兴趣的商品
2. 进入商品详情，点击"去出价"
3. 确认缴纳保证金（首次）
4. 输入出价金额
5. 点击"确认出价"

### 5.3 发布商品

1. 进入"发布"页面
2. 拍摄或选择商品图片
3. 填写商品信息
4. 设置拍卖规则
5. 点击"发布"
