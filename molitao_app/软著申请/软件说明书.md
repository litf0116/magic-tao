# 魔力淘软件说明书

---

## 第一章 软件概述

### 1.1 软件背景

随着移动互联网的快速发展，二手物品交易市场需求日益增长。「魔力淘」是一款专注于二手物品交易的移动应用，为用户提供商品发布、在线交易、即时通讯等一站式服务。

### 1.2 软件定位

「魔力淘」定位为二手物品交易平台，用户可以通过手机便捷地发布商品、参与交易、与其他用户实时沟通。

### 1.3 主要特点

1. **操作便捷**：简洁直观的用户界面，降低使用门槛
2. **实时交易**：支持商品信息实时更新，保证交易时效性
3. **安全保障**：保证金机制，降低交易风险
4. **即时通讯**：内置聊天功能，方便买卖双方沟通

## 第二章 功能介绍

### 2.1 用户认证模块

#### 2.1.1 登录注册

用户可以通过以下方式注册和登录：
- **账号密码登录**：输入用户名和密码进行登录
- **短信验证码登录**：通过手机验证码快速登录
- **微信一键登录**：通过微信授权快速登录，无需注册

#### 2.1.2 账户安全

- 密码登录启用/禁用
- 密码修改
- 手机号绑定/更换
- 多种登录方式管理

### 2.2 首页模块

首页展示平台核心内容：
- **Banner轮播**：平台活动、重要通知展示
- **广告位**：商品推荐、活动推广
- **文章资讯**：平台动态、行业资讯
- **快捷入口**：交易站、交易中心入口

### 2.3 交易站模块

#### 2.3.1 商品列表

- 分类筛选（全部、数码、服饰、家居等）
- 关键词搜索
- 热门词快速筛选
- 置顶商品展示
- 下拉刷新、上拉加载更多

#### 2.3.2 商品详情

- 商品图片浏览（支持多图）
- 商品名称、描述、价格
- 卖家信息
- 商品状态（在售/已售）

#### 2.3.3 商品发布

- 拍摄/选择商品图片
- 填写商品名称、描述
- 设置商品价格
- 选择商品分类
- 提交发布

### 2.4 即时通讯模块

#### 2.4.1 会话列表

- 展示所有聊天会话
- 未读消息红点提示
- 会话时间排序
- WebSocket实时消息推送

#### 2.4.2 私聊功能

- 一对一实时聊天
- 发送文字、图片消息
- 消息撤回
- 查看用户资料
- 加好友功能

#### 2.4.3 群聊功能

- 多人群组聊天
- 群公告查看
- 群成员管理
- 实时消息通知

### 2.5 支付模块

#### 2.5.1 保证金充值

- 支持微信支付
- 保证金缴纳
- 充值成功后可发布商品

#### 2.5.2 余额管理

- 账户余额查询
- 余额变动记录
- 保证金记录查询

#### 2.5.3 提现功能

- 余额提现申请
- 提现记录查询

### 2.6 订单管理模块

#### 2.6.1 买家订单

- 待付款订单
- 待收货订单
- 已完成订单

#### 2.6.2 卖家订单

- 待发货订单
- 订单管理
- 订单状态跟踪

### 2.7 通讯录模块

- 好友搜索
- 好友申请列表（同意/拒绝）
- 好友列表展示
- 快速发起聊天

### 2.8 个人中心模块

- 用户头像、昵称展示
- 统计数据（好友数、余额）
- 个人信息编辑
- 退出登录

### 2.9 设置模块

- 账户安全设置
- 消息通知开关
- 清除缓存
- 关于我们

- 隐私政策

### 2.10 公告模块

- 公告列表展示
- 按分类筛选

## 第三章 软件架构

### 3.1 技术架构

「魔力淘」采用 Flutter 跨平台框架开发，主要技术选型：

| 组件 | 技术方案 |
|-----|---------|
| 框架 | Flutter 3.x |
| 语言 | Dart 3.x |
| 状态管理 | Riverpod |
| 路由管理 | GoRouter |
| 网络请求 | Dio |
| 即时通讯 | WebSocket |
| 本地存储 | SharedPreferences |

### 3.2 模块划分

```
lib/
├── core/              # 核心模块
│   ├── router/        # 路由配置
│   └── theme/         # 主题配置
├── data/              # 数据层
│   ├── api/           # API 客户端
│   ├── models/        # 数据模型
│   └── repositories/  # 数据仓库
├── domain/            # 领域层
│   └── entities/      # 实体定义
├── presentation/      # 表现层
│   ├── pages/         # 页面
│   ├── providers/     # 状态管理
│   └── widgets/       # 通用组件
└── services/          # 服务层
```

### 3.3 后端服务架构

| 服务模块 | 功能说明 |
|---------|---------|
| 用户认证服务 | 注册、登录、账户安全 |
| 商品服务 | 商品管理、交易处理 |
| 支付服务 | 微信支付、退款、提现 |
| 消息服务 | 即时通讯、历史消息 |
| 内容安全 | 文本/图片内容审核 |
| 系统配置 | 功能开关、版本管理 |

## 第五章 使用说明

### 5.1 首次使用

1. 下载并安装应用
2. 打开应用，进入登录页面
3. 选择登录方式（账号密码/短信验证码/微信）
4. 登录成功后进入首页

### 5.2 购买商品

1. 在商品列表选择感兴趣的商品
2. 进入商品详情，查看商品信息
3. 点击"立即购买"或联系卖家
4. 完成交易

### 5.3 发布商品

1. 缴纳保证金（首次发布需缴纳）
2. 进入"发布"页面
3. 拍摄或选择商品图片
4. 填写商品信息
5. 点击"发布"

### 5.4 即时通讯

1. 进入聊天页面
2. 选择联系人或群组
3. 发送文字、图片消息
4. 查看历史消息记录
